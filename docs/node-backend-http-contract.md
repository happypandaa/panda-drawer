# Node 后端接口、代理和启动等待

2026-11-02 用户确认实施。本文规定本轮源码行为；安装包采用这些变更后才对用户生效。身份、数据、窗口和停止归属继续按 [Node 单目录运行](node-single-directory.md)执行。此次不读取、转换或清理已有应用数据。

## 接口地址由应用声明

`panda.json` 的 `backend.apiPrefixes` 是可选字符串数组。每项为区分大小写的绝对路径前缀，按完整路径段匹配。例如 Readio 可以声明：

```json
{
  "root": ".",
  "entry": "managed.mjs",
  "nodeMajor": 24,
  "protocolVersion": 1,
  "apiPrefixes": ["/v1"]
}
```

这是 `backend` 的片段，不是一份完整清单。`/v1` 同时匹配 `/v1`、`/v1/chat/completions`，不匹配 `/v10`。省略字段时保留默认 `['/api', '/tts']`；显式 `[]` 表示没有业务接口需要代理。新建 Node 项目显式声明自己的 `/api`。

每项必须有非空路径段，不接受根 `/`、首段 `_platform`、尾斜杠、空段、`.` 或 `..`、百分号转义、反斜杠、查询、片段及空白；列表不允许重复前缀。不要求现有应用把 `/v1`、`/graphql` 等业务地址改成平台指定名字。声明在本次启动时形成快照，改动下次启动生效。

分流顺序为平台保留路径、已声明后端接口、现有静态文件及页面回退规则。接口路径范围由作者明确声明；平台不把任意缺失文件自动转成后端请求。相同路径若位于已声明接口下，以后端为准。网页项目仍不允许声明 `backend`。

## 请求内容流式转发

原代理先将整个请求缓冲到内存，并在 64 KiB 截断。本轮取消该统一门槛，按后端接收速度逐段读取和转发，避免把完整上传装入内存。应用仍负责自己的大小、参数、文件及业务校验；后端的 413 等业务拒绝应如实返回。

实际等待下一段请求数据最多 15 秒；发送请求及等待响应头总预算为 120 秒。移除大小门槛不表示取消连接和时间管理。停止、窗口关闭、客户端断开或超时均须释放真实请求体和连接，并等待登记的工作结束，不以丢弃等待者代替停止。

## 普通 HTTP 信息保留

请求与响应默认保留端到端业务头及其多值，包括内容类型、长度和编码、下载文件名、缓存策略、ETag、条件请求、Range、流式恢复和自定义幂等标识。标准网络库负责 HTTP 连接定界，不转发逐跳字段及 `Connection` 点名的字段。

后端目标、Host 和本次实例 Bearer 由平台产生；浏览器的平台会话、认证及来源信息不能借普通业务头转发给后端。平台的来源检查、页面安全策略和会话 Cookie 继续由平台负责。后端不能用响应修改平台会话、认证或跳转边界。具体过滤列表以 [代理实现](../crates/platform-core/src/node_app_proxy.rs)及回归为准。

304 表示缓存内容未变化，允许正常返回。真正的业务重定向和 WebSocket 连接升级继续拒绝。普通业务缓存策略应保留；平台自己的安全头继续覆盖，未声明业务缓存策略时使用默认 `no-store`。

## 启动总等待和实际阶段

本次后端启动及页面代理准备的总预算为 30 秒，从取得本应用操作许可后受理本次启动任务开始；单次 HTTP 健康检查最多 10 秒，且包含在总预算内。各安全边界都检查同一截止时间，健康检查不重新取得一份完整启动预算。控制 ping 仍为 3 秒，正常停止宽限仍为 5 秒。启动健康检查只验证本机服务及本次实例，不调用 AI、TTS 等远程业务接口。

管理器提供本次启动实际阶段和已等待时间，界面据此显示准备、等待后端就绪、检查连接及准备页面等状态，不按经过时间猜阶段，不显示虚构百分比。状态读取不等待启动资源锁；成功、失败、选择其他应用和界面卸载会停止轮询，旧读取不能覆盖新任务。

超时后仍须完成真实清理；清理期间应显示收尾，不能承诺整个调用连同异常清理都在 30 秒内结束。系统原生窗口创建在后端管理器之外，不能为满足时间数字强制取消它或丢弃实际句柄。清理未确认时保留原有运行归属及再次启动门禁。
