# 最小静态页面：AI / 开发说明

## 范围与实际状态

这是拟议应用包格式 v1 的文档示例，包含预构建静态 HTML 和两类说明。当前平台没有实现该包的检测、安装或更新；本文件不是构建或安装成功记录。

## 架构与目录

- `local-app.json` 声明名称、版本、网页位置和资料路径。
- `dist/index.html` 是唯一运行页面，只有文本，无 JavaScript、外部资源、SDK 或设备调用。
- `docs/USER_GUIDE.md` 面向用户；本文件面向 AI 和开发者。
- 仓库中的根 `README.md` 解释规范示例，本包未声明复制它，不是应用用户指南。

目标运行方式是平台提供本地静态资源服务，在唯一原生应用窗口展示 HTML，重复打开只聚焦。浏览器仅作必要诊断；本例不存在独立 Node/Python 服务或额外数据库服务。

## 用户环境与交付

本例按前端优先原则交付现成 HTML，无 Node 后端；平台提供窗口及静态服务。用户无需另装 Node、npm、CLI 或其他服务，无在线账号、Key、联网或设备要求。开发所需工具与日常运行前提分开说明；平台内置 Node 不表示可在用户端安装依赖或构建本包。
