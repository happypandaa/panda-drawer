# 最小静态页面：使用说明

这是用于解释应用包格式的静态文字示例，不提供真实业务管理功能。当前平台尚未实现此类外部包安装；下述安装后的流程是目标说明，不是已上线功能。

## 能做什么

打开后查看一个文字页面，了解网页包可以只有预构建 HTML。页面没有新增、编辑、查询或数据保存功能。

## 开始使用

外部包安装功能完成后，在平台中按安装流程选择包含 `local-app.json` 的包根，查看范围与检测结果，确认安装，再主动打开实例。运行需要平台本地服务开启；不需要开发该页面的 AI、Node 或源码工程。

当前不要把本示例当作平台完整项目 ZIP 导入，也不要手工复制到工作区冒充项目登记。

## 配置

不需要配置，没有账号、API key、联网服务或设备权限。无需修改清单、源码或数据库。

## 使用与退出

打开后阅读文字即可。没有需要保存的输入，也没有离线待发送记录。页面本身不需要互联网；退出平台后不提供本机服务，不能将缓存页面当作服务仍在线。

## 数据和限制

本例没有业务表和用户附件，不产生个人业务记录。实际平台项目的备份/恢复由平台入口管理，不通过删除数据目录完成。若未来版本增加保存或配置功能，作者需同步本说明。

如果当前平台拒绝此目录，这是安装功能尚未实现的限制，不应通过改项目登记或跳过检测处理。
