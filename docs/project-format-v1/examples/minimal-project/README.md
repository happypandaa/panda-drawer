# 最小受管项目清单示例

`project.json` 是供 Schema 检查和编写参考的完整最小清单，ID 为虚构值。这里只提供清单，不提供数据库、源码、产物或登记记录，因此本目录不是可运行项目、完整项目备份或可安装应用包。

当前受管项目由平台“新建项目”流程生成其实际 ID、独立数据库、初始网页、匹配源码和文档。本示例不应复制进现有工作区的 `projects/`，也不应手工填补本机身份记录。完整 ZIP 导入仍使用平台导出的 `backup.json + project/` 归档。

`description`、`icon`、`runtimeRequirements` 是可选字段。本示例省略它们；需要网络或设备时，按[主规范](../../../project-and-app-format-v1.md)声明具体用途，Schema 不能代替运行期校验或系统授权。
