## 使用流程

1. 在管理窗口 **我的项目** 列表接入包含 `local-app.json` 的可信源码目录。先在详情弹窗展示声明，确认登记仍不执行应用代码；网页与 Node 卡片放在同一列表，用类型图标与文字区分。
2. 从卡片进入详情／打开应用。缺必填时先显示同一详情弹窗的配置 tab，每项一行；需要用途、获取步骤或官方帮助时点击对应说明按钮。不因缺配置禁用整个进入入口。普通字段留空使用作者默认值；密码框空白表示保持原 Key。缺少必填项可以保存，不能启动后端。
3. 点击保存。普通值与修订保存在本机应用槽；Key 按用户最新要求保存在该槽的 `configuration/credentials/` 私有文件中，目录权限 `0700`、文件权限 `0600`。这是本机文件权限保护，不是系统加密凭据库。读取配置只返回已设置状态，不返回保存的 Key。
4. 点击“打开应用”。平台核对声明、私有 Node 摘要和版本、配置修订、持久数据目录，在后台启动本应用唯一 Node 进程并注入声明中的变量；就绪后在唯一原生应用窗口显示页面。无需用户先启动服务，不执行 npm，也不使用系统 PATH 的 Node。
5. 再次打开只聚焦已有窗口，保留页面内容；关闭应用窗口收尾本应用全部受管 Node、普通子进程与连接。macOS 管理窗口 X 只隐藏并保留 Dock，不停止已开的应用与受管服务；点击 Dock、Reopen 或重复启动恢复同一个管理窗口。菜单退出／Cmd+Q 才收尾全部受管应用；非 macOS 管理窗口 X 维持退出。运行中保存新配置后，需要明确“重启并应用配置”，或关闭业务窗口后再打开。保存、选中应用、打开配置页和平台重新启动都不会自动启动应用；退出不终止用户独立启动的其他 Node 服务。

页面中的“已设置”表示有本机绑定，不代表服务商已接受此 Key。保存和启动健康检查不请求付费 AI/TTS；上游调用由用户使用应用功能触发。修改服务地址时必须明确替换 Key、移除绑定或确认把原 Key 绑定到新地址。

作者可在初次登记的 `local-app.json` 中提供可选顶层 `window` 初始尺寸；未提供时为 1080×780，之后默认使用该注册 UUID 对应的本机上次普通窗口尺寸，重复打开仍只聚焦。完整声明、`rememberSize`、最小值和固定数据根缓存规则见[应用窗口尺寸](app-window-runtime-contract.md#应用窗口尺寸)。已登记槽的整份清单摘要校验照旧，不能为添加尺寸字段直接改写现有来源声明或绕过门禁；当前没有声明更新入口。实际原生缩放与记忆行为须另记验收，不由下方旧原生运行记录代签。

## 当前内部边界与本轮交互要求

- 网页与 Node 入口统一为“我的项目”中的卡片，两类均显示图标和文字，详情／配置沿用页面内带 tabs 的弹窗；此前独立“Node 应用”页属于旧交付形态，本轮新交互待另记验收。原项目不改身份、不搬目录，也不覆盖其源码和业务数据。
- Node 应用登记在固定数据根的 `node-apps/<随机实例ID>/`，与工作区中的 project-v1 完全分开。`registration.json` 保存来源和声明摘要；`configuration/` 保存普通显式值、修订和本槽秘密文件的绑定，`configuration/credentials/` 才保存秘密值；`data/`、`cache/` 跨重启保留；每次 `runs/` 下的运行目录和临时目录换新。这是每个应用自己的受管本机目录，不是作者源码、可分享安装包或 Git 目录。
- 工作区迁移、备份、回收站及导出仍只处理原有项目，不包含这些独立 Node 槽；界面说明它们的保存范围。源码目录必须与整个平台数据根互不包含；不从原源码 `.env` 或原业务数据借配置。
- 一个槽最多一个应用窗口和一个子进程；重复打开及并发打开复用正在启动或已存在的实例。应用不通过外部浏览器、`window.open`、`target="_blank"` 或其他 WebView 新建窗口，脚本业务弹窗改在当前页面内呈现。关闭期间阻止迟到的启动结果再创建窗口。保存与启动在同一管理锁下获得带修订的快照；秘密只能传给目标子进程创建环境，不写临时 `.env`、启动参数、业务网页或诊断。目标 Node 能读到自己的 Key，可信源码接入不是安全沙箱。
- 用户明确要求不用 macOS 钥匙串，当前使用本槽私有秘密文件，不读、不迁移、不删除旧 Keychain 条目。秘密文件是明文，由当前系统用户的文件权限保护；具有同一用户文件访问权限的程序仍可读取，不能称为系统加密或沙箱。目录／文件权限或归属不符合要求时明确失败，不改存源码、`.env` 或其他路径。保存先写本次不可变秘密文件，再原子提交配置修订与绑定；失败只回滚本次新文件，不扫旧条目和恢复现场。断电持久性未实测。
- 每个运行应用有独立本机端口和网页会话，作为原生窗口内部传输。一次性入口换取 HttpOnly Cookie；Rust 向固定本机后端注入控制凭据，应用页面不获得它。代理支持 SSE 和音频 Range，关闭窗口或停止时撤销会话并断流。网页只暴露声明的静态目录，拒绝链接、目录穿越、外部脚本和跨源管理请求；不向用户提供“另开浏览器”作为标准运行方式。
- 每三秒观察进程及本机健康接口，异常时关闭网页入口并停止本应用；不自动重启，不将上游断网误当进程退出。应用关窗要求收尾本应用全部受管 Node 和普通后代；macOS 管理窗口 X 只隐藏，菜单退出／Cmd+Q 及非 macOS 管理窗口 X 才安全收尾全部受管应用。停止依据实际进程组和平台自身工作的结束，不要求业务正常退出；清理无法确认时继续保留归属。不杀用户独立 Node，不靠旧数字 PID 猜测。宿主硬崩溃后的记录按本页顶部第一阶段规则核对；本次开机内无法确认的记录继续阻止重开，早于开机的普通标记或完整 v2 身份可分别收尾／接管。主动逃离进程组的后代不属于 v1 仅按进程组停止的完整保证。
- 已登记声明变化或源码失联时停止启动、提示核对；其他应用仍可管理。此版本未提供声明更新入口，只钉住说明文件，不冻结整个源码目录；登记的开发者代码和依赖仍需可信。
