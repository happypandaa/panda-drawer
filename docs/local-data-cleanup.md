## 删除与保留范围

设置入口使用“清理所有本机项目内容”，说明“通常在卸载熊猫小抽屉前使用。将永久删除本软件管理的本机数据和代码，无法撤销”。预览须展示实际目录、明确的删除范围和保留范围，不把清理称为缓存整理。

| 内容 | 本入口的处理 |
| --- | --- |
| 当前网页项目及工作区 | 永久删除源码、项目 Git、网页产物、数据库、附件和工作区内资料，包括已迁移到其他位置且可验证归属的当前工作区 |
| 已安装 Node 应用 | 永久删除受管程序代次、依赖、登记、配置、私有 Key 文件、业务数据、缓存和运行记录 |
| 平台获取的源码副本及安装资料 | 永久删除固定数据根内受管的来源副本、安装与更新历史、失败现场及其他业务资料 |
| 旧备份、旧回收站、维护与恢复资料 | 纳入本次全量清理；不会因为普通单项目删除原本保留它们而继续保留 |
| 已登记的迁移历史目录 | 只有归属、目录身份和迁移记录均可核验时才纳入，包含符合条件的旧工作区；未知目录不按名称猜测或扩大扫描 |
| 本机设置及其他受管业务内容 | 随全量清理移除；固定应用身份不变 |
| 外部原始源码目录 | 保留，包括通过外部目录引用接入、由用户自行维护的原始源码及其中资料；移除平台登记和平台私有配置／数据 |
| 新导出的外部 ZIP | 按发布时登记的原项目归属和文件身份删除；被替换或离线时拒绝误报成功；不根据旧任务路径收养文件 |
| 原始导入 ZIP 和其他外部原件 | 保留，不搜索全盘删除同名或相关文件 |
| 平台程序及内置资源 | 保留 `.app` 或已安装的平台程序；用户在清理后自行卸载软件 |
| 项目网页存储与管理器网页偏好 | 按活归属记录调用系统 API 清理；项目 store 删除后再枚举确认不存在，管理器清空数据并确认记录为空。其他系统级 `Caches`／`Preferences` 文件不搜索全盘删除 |
| 最小安全控制记录 | 成功只保留固定数据根本体、环境标记和原实例锁；不保留成功清理任务、项目存储标记或回执 |

Node 槽位于固定数据根的 `node-apps/`，不会随网页工作区迁移；本入口必须覆盖两类位置，不能只删当前工作区后宣称清理完成。外部原始源码保留不代表其平台私有配置或业务数据也保留。

列出的受管目录会整体清空，其中自行放入或已经取消登记的文件同样属于删除范围。外部源码保护依据可核对的来源登记和历史绑定，不扫描任意业务文件或秘密猜测原路径；若一份代码已无来源记录且存放在待删工作区内，无法将它与普通工作区文件区分。需要保留的文件应先移出预览列出的所有目录。

## 关闭与执行

最终确认后锁定普通管理操作，停止界面刷新和写入入口。先封住新窗口、受管任务及文件工作，关闭业务窗口，停止并等待受管 Node、代理、会话、平台服务、数据库和已接纳 I/O 的真实完成。只有全部关闭工作均成功、核心关闭无问题时才执行删除；普通退出可接受的“资源已关闭但仍有错误”不能转为全量删除许可。

外部 AI、编辑器和数据库工具也须停止使用待清理目录。平台只约束自身受管操作，不构成同一系统用户下的文件访问沙箱。无法核验目录归属、目录身份变化、不可访问的迁移目录、未完成迁移或无法确认已停止写入时拒绝删除并保留诊断，不能为凑齐“全部清空”扩大目录范围或绕过保护。

执行持有同一实例所有权，使用现有不跟随符号链接、按目录身份核对的安全删除边界。进度和回执放在待删业务内容之外。已接纳的工作不因弹窗关闭、前端等待方丢失或重复点击而取消或执行第二次。

## 结果与失败

提交后禁止关闭确认弹窗、返回普通操作或再次提交。界面显示停止、清理和最终结果；结果未知时只查询已有操作，不自动重发删除。未确认关闭成功时不得开始删除。

完整成功后明确显示受管本机数据和代码已清理、外部原始源码及最小控制记录保留，项目网页存储已经系统确认删除、管理器网页偏好已经清空；其他系统级应用缓存／偏好文件仍可能保留，仅提供退出软件入口。成功不自动卸载程序。下次启动按同一固定应用身份建立空的受管项目环境，不得自动重建已删的项目、网页存储或主题偏好。清理中的管理器只有结果／退出流程，保持原生事件循环直到所有系统回执完成。

部分失败或中断应报告实际剩余范围；重开后重新预览范围，不能显示全部成功，也不承诺恢复已删除文件。保留未选入清理范围的资料，不自动重试或在重启时继续删除。拒绝、失败、未知结果与成功的界面状态须分别表达。

## 平台与验证边界

本功能不开放当前 Windows 运行门禁，也不代表 Windows 安装器、NSIS 清数据选项或卸载／重装已验收。Mac 与 Windows 均须在各自已开放能力和真实文件安全边界内实现、检查，不能互借通过结论。

自动测试只能使用明确可丢弃目录和测试项目，不执行固定开发数据根的真实全量清理；既有源码、固定 SDK、数据库、附件、备份、旧回收与恢复证据继续保全。前端模拟确认通过不证明实际原生窗口关闭或文件删除，核心可丢弃目录测试不证明正式安装包、最低系统或 Windows 实机行为。
