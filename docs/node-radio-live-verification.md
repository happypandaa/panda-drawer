## 试用形态

执行引擎来自已构建的内部 `.app`，Node 24.22.0 / darwin arm64，官方二进制摘要核验通过；运行环境的 PATH 中没有系统 Node。

本轮使用忽略目录中的一次性本机浏览器适配器：以最小环境启动 `server/managed.mjs`，初始化实例，提供原静态页面，并在服务端向受管后端注入实例认证。浏览器没有得到实例 token 或 AI Key。适配器只监听动态 loopback 端口，检查 Host/Origin，转发同源 API 与 SSE；这不是已经接入平台的 Rust 项目代理、正式安装入口或产品管理界面。此前 Rust 生命周期试验结果见[首次验证](node-runtime-trial-verification.md)，本轮不冒用其范围。

DeepSeek 凭据通过关闭终端回显的输入进入试验进程，只注入目标后端的创建环境；不写源码、清单、`.env`、浏览器、报告或提交。原输入补齐官方 `sk-` 前缀后认证成功，不在此记录凭据内容。`/models` 返回可用模型后，本次选择 `deepseek-flash`，通过现有 Anthropic Messages 兼容客户端调用 `https://api.deepseek.com/anthropic/v1/messages`；这是官方支持的[兼容入口](https://api-docs.deepseek.com/guides/anthropic_api/)。未改原应用的服务商/模型默认配置，未持久保存真实密钥。

## 本次修复

真实链路发现此前离线验证未覆盖的音乐阻塞：网易云 SDK 4.41.1 的函数入口跳过公钥准备，搜索正常但默认 xeapi 的播放地址请求失败。`server/music-sdk.mjs` 现在在首次播放请求时惰性调用 SDK 自带 helper，保留其校验，将公钥以 0600 原子写入隔离临时目录；启动、健康和搜索不触发此请求。并发初始化复用，失败可重试，固定公钥请求受五秒、64 KiB、取消和禁止跳转约束。

上述约束由只匹配 SDK 固定公钥地址的临时 Axios 拦截器提供，结束后移除；不改变其他请求。普通 SDK 歌曲请求的取消以及长期 xeapi 密钥轮换仍未解决，不能据此宣称全天稳定或具有完整在途取消能力。

`public/app.js` 现遵守后端 `loginEnabled=false`，显示游客模式并禁用账号连接，独立模式保持原行为；`server/app.mjs` 的缺语音密钥提示不再引导到尚未交付的配置界面。对应源码修改前已在本机忽略目录保全。

使用包内 Node 执行 radio 全部测试，**43/43 通过**；新增公钥回归使用人工网络替身，分别检查惰性/并发初始化、失败重试、不泄漏上游错误、取消与原子文件、请求预算及拦截器清理。真实网络及浏览器的证据与这些离线测试分开记录。
