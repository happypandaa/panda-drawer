# 操作消息

2026-10-22，按用户确认精简操作反馈：操作结果不再作为共用提示条在主页、新建和详情之间流转，也不表示应用仍在运行。

- 普通打开、创建成功及重新加载不另加常驻成功横幅，界面变化和当前状态作为结果。
- 新建、项目操作、配置和 AI 说明的错误留在相应操作区。复制结果放在 AI 说明按钮旁，关闭详情或切换项目后清除；手动复制全文和失败处理方式继续保留。
- 跨页面的列表读取、维护状态、任务读取异常和工作区服务切换提醒集中到顶部“消息”。相同来源使用稳定编号替换，避免轮询时重复堆积；读取恢复后自动清除对应异常。
- 网页与 Node 删除完成后，结果集中到“消息”，显示系统废纸篓的实际去向；旧版任务只作历史核对，不再引导进入已退役的回收界面。失败和结果不明仍在原删除操作区核对，不当作成功移除。
- 消息只属于本次应用会话，可单条或全部清除，不自动弹窗或自动过期。条数表示当前消息数。管理任务、删除回执、迁移及恢复证据仍按原合同保留，不随清除消息删除。

验证使用可丢弃 DOM 与前端样本，没有操作现有项目。221项界面检查及 TypeScript/Vite 构建通过，覆盖页面隔离、重复读取失败去重、手动刷新读到最终任务后的恢复清除、表单草稿和错误保留、后台删除结果入口及消息窗口焦点。内置浏览器检查了亮色、暗色、默认960×640和最小640×480窗口；样本未连接真实原生服务，不由此宣称完成真实删除或迁移验收。
