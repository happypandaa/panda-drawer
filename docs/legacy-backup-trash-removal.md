# 旧版回收站、旧备份与维护的移除

确认日期：2026-10-26（Asia/Shanghai）。用户确认：开发环境已于 2026-10-25 [重置](development-identity-reset.md)，旧回收项、旧备份和维护现场都已不存在；当前版本也不会再产生这些资料，因此删除全部兼容代码，不再保留。

## 删除的内容

| 范围 | 删除 |
| --- | --- |
| 旧回收站 | 回收项的列表、详情、恢复、永久清除；旧版“移入回收站”的执行与重启核对；迁移时的回收项身份重绑定（`trash-rebindings.json` 不再生成）；项目 ID 冲突检查中的回收站扫描；HTTP `trash*` 路由、`trash` CLI 命令、`trash_*` 原生命令；管理界面“历史保留项目”页签 |
| 旧备份与维护 | 备份列表、详情、创建、恢复（含恢复日志的启动核对）；进入／结束维护；自动保留份数规则；HTTP `projects/{id}/backups*`、`restore`、`maintenance`（POST）与 `maintenance/end`；`backup` CLI 命令与 `maintenance begin/end`；对应原生命令；早已无入口的 `BackupMaintenancePanel` 界面 |
| 历史清理候选 | “旧版保留项目”和“已完成恢复的原现场”两类；只剩迁移前的旧工作区 |
| 空间统计 | 工作区的 `backups`、`trash` 分类及项目的历史备份统计 |
| 新工作区初始化 | 不再创建或要求 `workspace/backups/` 目录 |
| 历史脚本 | `m3-*` 全部、`m4-live-test.mjs`、`m4-migration-test.mjs`、`workspace-identity-live-test.mjs`（均只能对旧版服务运行） |

## 保留的内容

- 项目导出、导入、复制使用的完整 ZIP 编解码、校验和 SQLite 一致性快照（`backups.rs` 中的归档原语）。导入仍拒绝维护中或状态未知的旧归档。
- `maintenance status`：读取项目当前的忙碌、恢复门禁、待构建和最近构建信息，界面依赖它；`maintenanceId` 参数仍被接受，以兼容既有控制状态。
- 项目控制状态（`ControlState`）字段保持不变，未做格式迁移。启动时若遇到旧版本留下的回收站操作日志，只报告“需要处理”并保留现场，不执行。
- 业务页面运行时中的 `trashed` 状态字段仍保留（它在当前版本中表示项目已被删除），未改变 SDK 与运行提示契约。

## 已知缺口（改动前即存在）

`ProjectStore::rebind`（数据库或项目目录被外部替换后的重新登记）原本只由“结束维护”调用；进入维护在 10-24 已退役，所以该入口此前就已无法到达。本次保留这个受检查的函数，但没有新增入口：数据库文件被外部替换的项目会停在“需要重新登记”，需要另行设计显式入口。

## 验证

在云端 Linux 副本中执行。平台运行时只放行 macOS，为在 Linux 上运行测试，临时加入“把 Linux 视为 macOS”的本地补丁，改动前后同样条件运行，该补丁不在提交中。依赖 macOS 文件身份、进程组或系统工具的测试在 Linux 上本就失败，按改动前后的失败清单对比判断。

- `platform-core` 库测试：改动前 581 通过、122 失败、53 忽略；改动后 537 通过、122 失败、53 忽略。两次失败清单逐项相同（Node 安装、Git 工具、数据取回登记等依赖 macOS 文件身份或真实工具），没有新增失败。另有两项进程测试在 Linux 上不结束，两次都跳过。
- 删除 45 项只针对已移除功能的测试（备份 1、维护 23、回收站 9、历史清理 7、服务层 4、CLI 1，CLI 一项改写为“旧命令已不存在”）。其中 4 项通用的历史清理流程测试（计划过期、计划变化、源码取回守卫、HTTP 鉴权）原本借用回收项作测试对象，在下一步新增清理类别后补回。
- `platform-cli` 测试 23 项通过。
- 只在 macOS 编译的测试代码：在验证副本中临时去掉条件编译做类型检查，改动前后得到相同的 3 个 macOS 专属 API 错误，无其他错误。
- 前端：`npm run test:ui` 对应的 447 项通过（改动前 452 项，删除 5 项备份面板和回收站测试）；TypeScript 与 Vite 构建通过。
- `cargo fmt --check` 通过。

未在 macOS 上编译桌面壳（Linux 缺少 WebKitGTK，只做了命令注册列表的静态核对），未构建安装包，未做原生界面验收。
