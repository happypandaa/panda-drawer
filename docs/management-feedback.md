# 管理界面操作提示

确认日期：2026-10-23。用户已确认：普通完成提示自动消失，错误由用户关闭；提示属于产生它的页面或弹窗，局部操作在原位置反馈。离开原页面或关闭原弹窗后丢弃所属提示，回到原处也不重新弹出。

## 显示与关闭

| 类型 | 显示规则 |
| --- | --- |
| 普通成功 | 本轮实现选择 **5 秒**后自动消失，也可手动关闭；后来的提示拥有自己的期限，旧计时器不能关闭新提示 |
| 错误、需核对的未完成结果 | 原上下文仍可见期间持续显示，直到用户关闭；刷新、计时器、新的成功或开始其他操作不能顺便清除 |
| 迁移／清理进行中 | 跟随真实任务状态，不套用成功提示的计时器；取得任务最终结果后结束进行中显示，结果保留在对应任务位置 |

错误持续显示与离开上下文后丢弃并不冲突：用户留在原页面／弹窗时有机会阅读并手动关闭；离开或关闭是显式结束这个位置的显示。丢弃提示不取消后台任务、不撤销操作、不删除草稿或操作记录，也不表示错误已经解决。

任务状态暂时读不到，不能当作任务已结束，也不能证明它仍在运行。任务未到最终状态时仍按实际情况暂停相关写操作；成功、失败或中断等最终结果都不能继续显示旧的“正在进行”。若最终结果仍要求工作区暂停或核对收尾，应显示对应状态并保留原门禁，不能为移除旧提示而假装已经恢复。任务结果与短期通知分别保留，自动消失的完成提示不替代需要阅读的结果和诊断。

## 提示归属

项目列表的进入／删除结果，以及当前页面的启动或列表读取错误，可在所属页面提示。详情中的 AI 交接、复制路径、构建、基本信息、配置、来源检查等操作，在对应弹窗、面板或任务结果处反馈，不从局部位置冒到管理页顶部。

新建后自动打开详情时，完成说明归属新打开的详情；关闭详情后不回到列表重放。切换页面、关闭弹窗、换项目或工作区／服务身份变化时撤销旧显示资格。异步操作可能已经完成，仍须在对应任务记录核对；迟到结果不能把旧操作的提示带进新上下文，再次打开同名页面或同一项目也不能恢复上一次显示资格。

成功必须按实际结果分类。例如删除返回 `metadataCleanupPending` 时，登记收尾尚待核对：受管实例说明本实例文件已删除，外部引用说明已从平台移除且原目录／文件未改动。提示须保留实际完成范围、未完成收尾与“不要重复提交删除”，不能作为普通完成提示在5秒后消失，也不能暗示再次删除即可解决。剪贴板失败时仍有手动复制材料的，应在原交接位置说明替代步骤。
