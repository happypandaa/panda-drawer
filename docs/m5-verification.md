- 原生下载底层：3/3 Rust 函数级测试通过，覆盖本项目/精确 blob origin、符号链接/目录身份替换/超限保护、原子发布与保护路径拒绝。项目窗口和管理页附件下载复用独立临时名、安全发布、保存前后目的检查和父目录同步。浏览器下载先进入私有暂存，再以非阻塞原生对话框选择保存位置；不自动写入 Downloads。日志：`.test-artifacts/m5-browser-download-tests.log`。尚未操作真实保存对话框。

外链实现边界：项目顶层不会导航到外部网站。允许的 HTTPS 目标先进入原生确认，只有用户明确同意后才交给默认浏览器。确认请求也可能由项目脚本发起；当前实现没有识别可信链接点击的原生桥接，不能声称已验证请求来自一次链接点击。

原生 WebView 权限回调仅处理新的权限请求；浏览器已有的许可偏好可能直接生效。新文档的 Permissions-Policy 和标准助手的设备释放仍是独立环节。运行声明变更不等于瞬间撤销所有旧页面权限，自行调用 getUserMedia 的任意项目代码也不受标准助手完全控制。

最终包校验脚本为 `scripts/m5-package-verify.mjs`，已通过语法检查但尚未执行。它会创建独立证据目录，校验开发身份、架构、签名、Info.plist、实际 entitlements、DMG 只读挂载全条目一致和 8 处 SDK 摘要，同时再次核对 M4 保留副本。
