# 本地目录检查、初始化与添加

更新：2026-11-01，统一清单批次 3。网页与 Node 均使用根部 `panda.json`，字段见[项目格式](panda-project-format.md)。添加原目录引用，不创建程序副本，不修改作者清单，不安装依赖或执行项目。

## 三条路径

| 检查结果 | 操作 | 文件范围 |
| --- | --- | --- |
| `empty` 普通空目录 | 一次确认“生成并添加项目” | 生成零第三方依赖 Node 起始项目并登记；不启动、不安装 |
| `ready` 有效网页或 Node 项目 | 预览名称、入口、配置和归属后添加 | 只登记用户原目录，不复制或改写 |
| `needs-review` 其余目录 | 查看依据，复制给 AI 的只读检查说明，适配后重查 | 不补清单、不运行命令、不自动发送资料 |

隐藏文件也算目录内容；不自动清空目录。无权限、路径不安全或超出预算时停止，不能当作空目录。共享解析器和 JSON Schema 同时用于本地、Git、运行及构建入口。

网页只需有效 `runtime: "web"` 清单，不强制 SDK、构建或 React。缺少网页入口仍可添加：声明了 `development.build` 显示“需要构建”，没有则显示“入口缺失”。检查和添加不会代为构建。Node 必须已有前后端入口、固定 Node 24 可执行代码及协议 1；Node 不接受网页构建声明。

## 空目录生成

起始项目使用 `panda.json`、`web/index.html`、`web/app.js` 和 `backend/server.mjs`，附 README、DEVELOPMENT、零第三方依赖包及锁文件。按钮一次完成生成和持久登记；不再串联两次用户确认。确认前目录变化时不覆盖新内容，须重新检查。

用户选择的文件夹及其中生成的代码仍归用户所有。生成时的私有归属记录仅用于绑定本次创建文件和中断状态，不取得递归删除用户目录的权限。失败保留已创建文件，显示真实登记结果；不自动回滚、覆盖或重复生成。重新检查后可添加已完成的有效项目。同一真实目录已有登记时沿用已有实例。

平台登记、配置、密钥、日志和缓存位于私有实例目录；不依赖项目内 `.platform`、应用 ID 或复制进去的技能文件。给 AI 的说明直接包含独立技能全文，不要求作者安装全局技能。

## 只读评估与确认

读取公开清单、README、源码和包声明，不读取真实 `.env`、密钥、数据库或私人附件；不安装、构建、启动或登录。AI 给出“可接入／需适配／当前不适合／信息不足”及文件依据。用户另行授权适配后才修改。

预览返回 `expectedRevision`；添加和初始化重新核对所选根身份、清单及声明文件。确认不是整棵工程快照，也不取得系统写锁。检查后修改须重新检查，过期、迟到或结果未知的响应不能触发覆盖或重复登记。生成阶段额外核对本次文件身份和摘要，不能自动采纳被并发替换的另一项目。

Node 必需运行依赖明确缺少时显示准备提示；共享依赖、workspace、无法判断或只有开发依赖时不推断缺失。提示不证明依赖完整，也不改变只读检查范围。用户准备后刷新，不必删除重加。

## 数据和删除

文件数据为项目 `data/`，Node `APP_DATA_DIR` 指向这里；启用网页 SDK 的数据库和附件按需创建。浏览器的 localStorage、IndexedDB、Cookie 位于平台窗口存储。

删除用户本地项目保留整个文件夹、Git 和 `data/`；私有登记、配置、密钥、日志、缓存、任务及浏览器数据被清除。重新添加不能读取先前实例的浏览器数据。删除提示分别说明文件数据保留和浏览器数据清除。

## 原生接口与验证边界

`node_app_directory_inspect` 只读检查；`node_app_directory_register({sourcePath, expectedRevision})` 分流网页／Node 登记；`node_app_directory_initialize_and_register` 完成空目录生成与登记。底层 initialize 命令仅生成，不代表已经加入列表。正常退出拒绝新操作并等待已接受操作结束。

实际批次验证记于[实施记录](unified-project-manifest-implementation.md)。DOM 模拟不证明原生选择器、窗口或系统权限；临时目录测试不证明任意外部仓库兼容。检查成功不等于已经运行或验证业务功能。
