# Clack

选一篇文章，安静地练一会儿打字。Clack 支持中英文逐行对照输入，实时标记对错，打满一行后继续下一行。

应用地址：[GitHub](https://github.com/happypandaa/Clack.git) / [Gitee](https://gitee.com/mycolorfuldays/clack.git)

## 能做什么

- 选择内置中文或英文文章，按名称搜索和筛选。
- 一边输入，一边查看正确与错误的位置，长文章跟随当前输入行滚动。
- 中文和英文分别记录练习历史与速度，暂停或离开窗口时停止计时。
- 在应用里导入、导出练习记录，留一份自己的备份。

不需要账号或 API Key。添加完成后，日常练习不需要联网，练习记录和设置保存在自己的电脑上。

## 添加并开始练习

1. 在熊猫小抽屉点「添加应用」，从「推荐应用」里找到 Clack，点「添加」；也可以在「有应用链接」中粘贴上面的应用地址。
2. 按提示确认准备，等待完成后点「打开」。
3. 选一篇文章，开始练习。

第一次打开时，Clack 会自动完成初始准备。准备失败时可以按提示重试，已有练习记录会保留。

## 想调整练习方式

在应用详情点「用 XX 改」，告诉自己的 AI：

> 我想加一个 60 秒限时模式，结束后显示速度和正确率。

也可以增加喜欢的文章、调整字体或成绩展示。改完后按 AI 的说明关闭窗口、点「准备应用」，再重新打开，检查新功能和以前的练习记录。
