# Clack

选一篇文章，安静地练一会儿打字。Clack 支持中英文逐行对照输入，实时标记对错，打满一行后继续下一行。

[查看源码与使用说明](https://github.com/happypandaa/Clack)

## 能做什么

- 选择内置中文或英文文章，也可以按名称搜索和筛选。
- 一边输入，一边查看正确与错误的位置，长文章跟随当前输入行滚动。
- 中文和英文分别记录练习历史与速度，暂停或离开窗口时停止计时。
- 通过应用自己的 JSON 导入、导出功能保存练习记录。

日常练习不需要在线账号或 API Key，也不调用外部 AI。练习历史与设置通过熊猫小抽屉保存在本机数据库中。

## 如何添加

在熊猫小抽屉点击「添加应用」，粘贴 [Clack 仓库链接](https://github.com/happypandaa/Clack)，按界面提示确认准备网页；已有本机源码时，也可以选择整个项目文件夹。

当前公开源码需要准备网页，并按 [README 的接入步骤](https://github.com/happypandaa/Clack/blob/main/README.md)完成首次数据库初始化。可以从详情把项目交给 AI，让它按随附的平台说明完成准备，再打开练习。无需自己安装数据库服务器。

本站已核对公开清单与当前项目格式；首次准备、中文输入法和真实窗口使用仍需在你的环境中验证。

## 想调整练习方式

从应用详情交给自己的 AI，试着增加适合你的文章、修改字体大小，或调整成绩展示。修改前关闭应用窗口，并要求保留已有练习记录；完成后准备应用，再重新打开检查。
