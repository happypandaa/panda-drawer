# Clack

选一篇中文或英文文章，跟着原文逐行练习。打满一行后会继续下一行，完成后可以回顾速度、准确率和错字，也可以单独再练一遍错字。

应用地址 [GitHub](https://github.com/happypandaa/Clack.git) / [Gitee](https://gitee.com/mycolorfuldays/clack.git)

## 添加并开始练习

1. 在熊猫小抽屉的「推荐应用」里找到 Clack，点「添加」。你也可以在「有应用链接」里粘贴上方地址。
2. 看到准备提示时，点「准备并添加」，等待完成后打开。
3. 第一次打开会自动完成初始准备。按篇幅或分类选一篇文章，就能开始练习。

Clack 无需账号、API Key 或额外付费服务。添加完成后，日常练习可以离线进行。中文和英文的练习历史分开统计，记录和设置保存在自己的电脑上，可以在历史页导出备份。

## 调整练习方式

在 macOS 的应用窗口上点「按你的想法改」，例如告诉 AI「我想加一个 60 秒限时模式，结束后显示速度和正确率」。按 AI 的说明准备新版，再用「重新加载」查看。不同系统的操作见[常见问题](/wiki/faq/)。
