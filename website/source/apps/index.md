# 应用

这四款应用都可以在熊猫小抽屉的「推荐应用」中找到。点某款应用的「添加」后，熊猫小抽屉才会下载它。也可以把下方的应用地址粘贴到「添加应用」的「有应用链接」中。

## [拾闻（Gleaner）](/apps/gleaner/)

告诉自己的 AI 想看什么，让它收集和整理资讯，再回到拾闻阅读、收藏和反馈。需要一个能读写本机文件和联网搜索的 AI 工具。

应用地址 [GitHub](https://github.com/happypandaa/gleaner.git) / [Gitee](https://gitee.com/mycolorfuldays/gleaner.git)

## [Clack](/apps/clack/)

选一篇中文或英文文章，逐行练习，结束后回顾速度、准确率和错字。日常练习无需账号或 API Key。

应用地址 [GitHub](https://github.com/happypandaa/Clack.git) / [Gitee](https://gitee.com/mycolorfuldays/clack.git)

## [Readio](/apps/readio/)

逐句听读英语、翻译查词，收藏想复习的句子和生词。需要 DeepSeek 和 Fish Audio 的 API Key。

应用地址 [GitHub](https://github.com/happypandaa/Readio.git) / [Gitee](https://gitee.com/mycolorfuldays/readio.git)

## [Radio Bob](/apps/radio/)

说一句想听什么，让 Bob 选歌并写几句中文串词。需要 DeepSeek API Key，Fish Audio 主持语音可选。[查看配置](/apps/radio/#配置)

应用地址 [GitHub](https://github.com/happypandaa/radio-bob.git) / [Gitee](https://gitee.com/mycolorfuldays/radio-bob.git)
