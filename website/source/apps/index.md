# 我做的应用


一些从自己的需求出发，慢慢做出来的小应用。先从一台个人电台开始。

## [Radio Bob](/apps/radio/)

一台本机运行的个人 AI 电台。告诉 Bob 你想听什么，让它选歌、写几句中文串词；也可以自己搜索，把喜欢的音乐放进待播队列。

你可以保存音乐品味，让下一次点歌有更多自己的偏好。应用运行在熊猫小抽屉提供的窗口里，AI 和音乐功能需要联网。

[认识 Radio Bob](/apps/radio/) · [查看安装方法](/apps/radio/install/)
