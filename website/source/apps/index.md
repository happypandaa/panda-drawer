# 应用

在熊猫小抽屉点「添加应用」，从「推荐应用」选一款，点「添加」就会下载。第一次用，可以先从 Clack 开始。你也可以把下方的 GitHub 或 Gitee 地址粘贴到「有应用链接」中。

## [Clack](/apps/clack/)

{% screenshot a01-clack-practice.webp 1440 746 Clack 练习页显示文章、开始练习按钮和记录入口 %}

选一篇中文或英文文章，逐行练习，结束后回顾速度、准确率和错字。

**使用条件**　练习无需账号、API Key 或 AI 工具。

应用地址 [GitHub](https://github.com/happypandaa/Clack) · [Gitee](https://gitee.com/mycolorfuldays/clack)

## [拾闻（Gleaner）](/apps/gleaner/)

告诉自己的 AI 想看什么，让它收集和整理资讯，再回到拾闻阅读、收藏和反馈。

**使用条件**　用于收集资讯的 AI 工具需要能读写本机文件、联网搜索。拾闻里无需填 API Key。

应用地址 [GitHub](https://github.com/happypandaa/gleaner) · [Gitee](https://gitee.com/mycolorfuldays/gleaner)

## [Readio](/apps/readio/)

逐句听读英语、翻译查词，收藏想复习的句子和生词。

**使用条件**　需要 DeepSeek 和 Fish Audio 的 API Key。

应用地址 [GitHub](https://github.com/happypandaa/Readio) · [Gitee](https://gitee.com/mycolorfuldays/readio)

## [Radio Bob](/apps/radio/)

说一句想听什么，让 Bob 选歌并写几句中文串词。

**使用条件**　需要 DeepSeek API Key，Fish Audio 主持语音可选。[查看配置](/apps/radio/#配置)

应用地址 [GitHub](https://github.com/happypandaa/radio-bob) · [Gitee](https://gitee.com/mycolorfuldays/radio-bob)
