# 我做的应用

一些从自己的需求出发，慢慢做出来的小应用。先看看能做什么、需要准备什么；用起来后，再交给自己的 AI 改成喜欢的样子。

## [Clack](/apps/clack/)

中英文打字练习。选一篇文章，逐行输入，实时查看对错，分别记录中文和英文的练习成绩。日常练习不需要在线账号或 API Key。

[了解 Clack](/apps/clack/) · [查看源码](https://github.com/happypandaa/Clack)

## [Readio](/apps/readio/)

个人英语听读工具。粘贴一篇英文文章，逐句听音频、翻译和查词，把想复习的句子与生词收藏起来。需要自己的 DeepSeek 和豆包语音 API Key，以及网络与可用额度。

[了解 Readio](/apps/readio/) · [查看源码](https://github.com/happypandaa/Readio)

## [Radio Bob](/apps/radio/)

一台个人 AI 电台。告诉 Bob 你想听什么，让它选歌、写几句中文串词；也可以自己搜索，把喜欢的音乐放进待播队列。

源码已公开；公开版本仍需适配当前熊猫小抽屉的项目格式，再添加使用。

[认识 Radio Bob](/apps/radio/) · [添加与配置](/apps/radio/install/) · [查看源码](https://github.com/happypandaa/radio-bob)

## 如何添加

在熊猫小抽屉点击「添加应用」，可以粘贴兼容的 GitHub／Gitee 应用链接，或选择本机文件夹。每个应用的准备步骤见介绍页；公开源码不表示任何版本都能直接运行。

熊猫小抽屉目前仍是内部开发版，公开安装包尚未发布。[入门指南 →](/wiki/getting-started/)
