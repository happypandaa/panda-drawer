# 应用

挑一个现成的小应用用起来，哪里不顺手，就交给自己的 AI 改。

## [Clack](/apps/clack/)

中英文打字练习。选一篇文章，逐行输入，实时查看对错，分别记录两种语言的练习成绩。不需要账号或 API Key，适合第一次试用。

[了解 Clack](/apps/clack/)

应用地址：[GitHub](https://github.com/happypandaa/Clack.git) / [Gitee](https://gitee.com/mycolorfuldays/clack.git)

## [Readio](/apps/readio/)

个人英语听读工具。逐句听音频、翻译和查词，收藏想复习的句子与生词。需要 DeepSeek 和豆包语音两把 API Key，两个服务都按量付费。

[了解 Readio](/apps/readio/)

应用地址：[GitHub](https://github.com/happypandaa/Readio.git) / [Gitee](https://gitee.com/mycolorfuldays/readio.git)

## [Radio Bob](/apps/radio/)

一台个人 AI 电台。说说你想听什么，让 Bob 选歌、写几句中文串词，也可以自己搜索和排队播放。需要 DeepSeek API Key，Fish Audio 主持语音可选。

[认识 Radio Bob](/apps/radio/) · [查看配置](/apps/radio/#配置)

应用地址：[GitHub](https://github.com/happypandaa/radio-bob.git) / [Gitee](https://gitee.com/mycolorfuldays/radio-bob.git)

## 如何添加

在熊猫小抽屉点「添加应用」，从「推荐应用」里挑一个，点「添加」；也可以在「有应用链接」中粘贴上面的应用地址。添加完成后，按应用介绍填写配置，再点「打开」。
