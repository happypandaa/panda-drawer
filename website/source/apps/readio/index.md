# Readio

把想读的英文文章放进来，一句一句听懂。Readio 把朗读、翻译、查词与收藏放在同一个学习窗口里。

应用地址：[GitHub](https://github.com/happypandaa/Readio.git) / [Gitee](https://gitee.com/mycolorfuldays/readio.git)

## 能做什么

- 粘贴英文正文，自动分句并生成逐句音频。
- 继续上次的学习进度，跳句或调整播放速度。
- 翻译句子，点击单词查看语境释义。
- 收藏句子和生词，回到原文复习。

## 添加与配置

在熊猫小抽屉点「添加应用」，从「推荐应用」里找到 Readio，点「添加」；也可以在「有应用链接」中粘贴上面的应用地址。等待添加完成后，在应用详情的配置里填写两把自己的密钥：

| 设置 | 用途 |
| --- | --- |
| DeepSeek API Key | 句子翻译和查词；可在 [DeepSeek 平台](https://platform.deepseek.com/api_keys)创建。 |
| 豆包语音 API Key | 逐句英文朗读；按配置页说明在火山引擎语音控制台的「API Key 管理」中创建。 |

两项都必填，**两个服务都按量付费**。生成音频、翻译和查词需要联网，先确认自己的账号有可用额度。保存配置后，再点「打开」。

## 学习记录怎么保存

文章、学习进度和收藏保存在这个应用窗口的浏览器数据中。需要备份时，在 Readio 顶部「⋯」菜单导出备份文件；导入会要求确认覆盖当前数据，音频需要重新生成。

**删除应用会清除这些学习记录**，即使是从「本机文件夹」添加、项目文件夹仍保留，也一样。删除前，先在 Readio 内导出需要的记录。

想调整学习方式，可以在应用详情点「用 XX 改」，告诉自己的 AI 想改什么。
