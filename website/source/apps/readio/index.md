# Readio

把想读的英文文章放进来，一句一句听懂。Readio 会分句并生成朗读音频，也能翻译句子、查词和收藏。再次打开文章时，可以接着上次的进度学习。

应用地址 [GitHub](https://github.com/happypandaa/Readio.git) / [Gitee](https://gitee.com/mycolorfuldays/readio.git)

## 添加与配置

在熊猫小抽屉的「推荐应用」里找到 Readio，点「添加」。也可以在「有应用链接」中粘贴上方地址。添加后，打开「应用配置」，填写自己的密钥。

| 设置 | 用途 |
| --- | --- |
| DeepSeek API Key（必填） | 句子翻译和查词。可在 [DeepSeek 平台](https://platform.deepseek.com/api_keys)创建。 |
| Fish Audio API Key（必填） | 生成逐句朗读音频。可在 [Fish Audio](https://fish.audio/app/api-keys/)创建。 |
| Fish Audio 模型（选填） | 留空使用 `s2.1-pro-free`，默认音色是 Jessica。 |

若推荐卡片仍显示「豆包语音」，请按添加后的「应用配置」填写 Fish Audio API Key。已有 Readio 的配置以该应用显示的字段为准。翻译、查词和朗读需要联网，具体额度与价格以服务提供方的说明为准。保存后，打开 Readio。

## 听读和保存记录

第一次打开可以先试一篇内置文章，也可以点「添加文章」粘贴自己的英文正文。点击句子工具条播放、翻译或收藏，点击单词查词。要复习时，到「句子」和「生词」查看收藏。

文章、学习进度和收藏保存在这个应用窗口的浏览器数据里。需要备份时，从顶部菜单导出。导入会要求确认覆盖当前数据，朗读音频需要重新生成。删除 Readio 会清除这份学习数据，请在删除前导出需要保留的记录。
