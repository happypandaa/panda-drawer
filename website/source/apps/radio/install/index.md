# 添加与配置 Radio Bob

Radio Bob [源码已公开](https://github.com/happypandaa/radio-bob)。截至 2026-11-03，公开主分支仍使用旧平台格式，缺少当前版需要的 `panda.json`，**需要先适配，不能直接添加使用**。

## 1. 先准备兼容的项目

如果已有作者交付、符合当前格式的文件夹，在熊猫小抽屉点击「添加应用 → 本机文件夹」，选择整个项目目录，查看检查结果后添加。平台直接使用这个文件夹，后续修改也在这里进行。

如果拿到的是当前公开源码，先把它作为自己的开发项目交给能修改本机文件的 AI，连同熊猫小抽屉提供的平台说明一起检查和适配。当前[项目格式](/wiki/app-types/)要求网页与 Node 应用都提供 `panda.json`；改一个文件名不等于完成适配。

检查未通过时，先按结果处理；不要重复添加。以后作者发布兼容版本后，才可以在「添加应用」中粘贴仓库链接，等待下载、检查和准备完成。

## 2. 填写自己的密钥

添加完成后，在应用详情打开「应用配置」。公开源码目前只声明以下两项；适配后的实际字段以应用界面和作者说明为准。

| 设置 | 怎么填 |
| --- | --- |
| DeepSeek API Key | 必填。用于选歌和生成串词，在 [DeepSeek 平台](https://platform.deepseek.com/api_keys)创建自己的密钥，并确认有可用额度。 |
| Fish API Key | 可选。用于生成主持口播，在 [Fish Audio](https://fish.audio/app/api-keys/)创建。留空仍可看文字串词和听音乐。 |

公开版本的服务地址、模型和音色已有默认值，不需要在平台填写一整组高级参数。不要把密钥写进源码、Git 或发给别人；保存配置后，明确点击「打开」才会启动应用。

## 3. 先搜索，再试着点歌

先搜索一首熟悉的歌，试一下播放、暂停和切歌，再给 Bob 一个简单的需求：

> 给我推荐一首适合晚上放松的歌，先不需要语音。

搜索到歌曲不保证有完整播放权限，按界面的试听提示理解即可。AI 选歌和语音还依赖服务商网络与额度；保存密钥成功不等于服务调用已经验证。

关闭 Radio 窗口会停止它的后台服务。以后重新打开，使用已保存配置；修改代码前先关闭窗口，完成后按 AI 给出的步骤重新打开和验证。

## 想按自己的习惯修改

从应用详情选择自己的 AI 工具，或复制完整提示词并关联这个项目文件夹。让 AI 先读懂现有应用，再提出需求，比如改选歌偏好、调整界面或增加一种筛选方式。

已有业务记录和音乐账号信息要保留；不要把重新添加当作更新或恢复办法。删除平台下载的应用会连同项目文件与数据一起删除；本机文件夹的文件保留，浏览器数据和私有配置仍会清除，确认前请核对范围。
