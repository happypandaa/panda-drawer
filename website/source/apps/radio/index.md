# Radio Bob

<img src="/images/bob.png" alt="Radio Bob 的像素头像" width="88" height="88">

一台个人 AI 电台。说说此刻的心情，或者给 Bob 一个具体的歌手、风格和场景，让它陪你找些音乐。

> “给我三首适合专注工作的歌，轻一点，不要太热闹。”

应用地址：[GitHub](https://github.com/happypandaa/radio-bob.git) / [Gitee](https://gitee.com/mycolorfuldays/radio-bob.git)

## 和 Bob 一起听歌

- **自然语言点歌。** 写下需求，Bob 推荐歌曲，再到曲库里寻找可用音源。
- **中文主持串词。** 推荐之外，还有几句简短、松弛的中文介绍。配置 Fish Audio 后可以听主持口播；留空仍能看文字、听音乐。
- **自己搜索和排队。** 直接找一首歌，立即播放或加入待播队列，用播放器暂停、继续和切歌。
- **保存自己的品味。** 记下喜欢的歌手、风格和不喜欢的类型，让后续点歌带着自己的偏好。

界面支持深浅主题，也能显示歌曲封面和歌词。应用在自己的电脑上运行；选歌、语音和音乐需要联网。

## 添加

在熊猫小抽屉点「添加应用」，从「推荐应用」里找到 Radio Bob，点「添加」；也可以在「有应用链接」中粘贴上面的应用地址。等待添加完成，再填写配置。

## 配置

在应用详情的配置里填写自己的密钥：

| 设置 | 怎么填 |
| --- | --- |
| DeepSeek API Key | 必填，用于选歌和生成串词。在 [DeepSeek 平台](https://platform.deepseek.com/api_keys)创建，并确认有可用额度。 |
| Fish API Key（可选） | 用于生成主持口播。在 [Fish Audio](https://fish.audio/app/api-keys/)创建；不填仍能看文字串词、听音乐。 |

这些在线服务的费用由相应服务商收取。其他选项使用应用已有的设置，填好密钥并保存后，点「打开」。

## 先搜索，再试着点歌

先搜索一首熟悉的歌，试试播放、暂停和切歌，再告诉 Bob：

> 给我推荐一首适合晚上放松的歌，先不需要语音。

搜索到歌曲不保证能完整播放。歌曲是否可播、是否只有试听，取决于曲目和账号权限，按界面提示理解即可。需要连接网易云账号时，使用应用内的扫码入口。

再次打开会回到已有窗口，关闭 Radio 窗口会停止它。聊天记录和音乐品味保存在自己的电脑上；它目前没有麦克风输入、定时节目或多设备同步。

想让 Bob 更合自己的习惯，可以从应用详情点「用 XX 改」，把想法告诉自己的 AI。
