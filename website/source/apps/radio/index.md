# Radio Bob

<img src="/images/bob.png" alt="Radio Bob 的像素头像" width="88" height="88">

告诉 Bob 你想听的歌手、风格或场景，它会从曲库找可播放的歌曲并写几句中文串词。你也可以直接搜索、调整待播队列，或记下自己的音乐偏好。

应用地址 [GitHub](https://github.com/happypandaa/radio-bob.git) / [Gitee](https://gitee.com/mycolorfuldays/radio-bob.git)

## 添加

在熊猫小抽屉的「推荐应用」里找到 Radio Bob，点「添加」。也可以在「有应用链接」中粘贴上方地址。等待添加完成，再填写配置。

## 配置

| 设置 | 用途 |
| --- | --- |
| DeepSeek API Key（必填） | 用于选歌和生成主持串词。可在 [DeepSeek 平台](https://platform.deepseek.com/api_keys)创建。 |
| Fish API Key（可选） | 用于生成主持口播。可在 [Fish Audio](https://fish.audio/app/api-keys/)创建。留空仍能看文字串词、听音乐。 |

在应用详情的「应用配置」里保存密钥，再点「打开」。选歌、语音和音乐需要联网。AI 与语音服务按用量收费，具体额度和价格以服务提供方的说明为准。

## 先搜索，再点歌

先搜索一首熟悉的歌，试试播放、暂停和切歌。然后可以说「给我推荐一首适合晚上放松的歌，先不需要语音」。

音乐能否播放、能播放多久，取决于曲目和账号权限。部分歌曲只提供试听。要听主持口播，填写 Fish API Key 后开启自动口播。

聊天记录和音乐品味保存在自己的电脑上。关掉 Radio Bob 的窗口会停止电台，下次打开可以接着用。
