# Radio Bob


<img src="/images/bob.png" alt="Radio Bob 的像素头像" width="88" height="88">

一台本机运行的个人 AI 电台。说说此刻的心情，或者给 Bob 一个具体的歌手、风格和场景，让它陪你找些音乐。

> “给我三首适合专注工作的歌，轻一点，不要太热闹。”

[查看安装方法](/apps/radio/install/)

## 和 Bob 一起听歌

- **自然语言点歌。** 写下需求，Bob 推荐歌曲，再由应用到曲库匹配可用音源。
- **中文主持串词。** 推荐之外，也有几句简短、松弛的中文介绍。配置 Fish Audio 后可尝试生成主持声音；不配置语音仍能看文字、听音乐。
- **自己搜索和排队。** 直接找一首歌，立即播放或加入待播队列，用播放器暂停、继续和切歌。
- **保存自己的品味。** 记下喜欢的歌手、风格和不喜欢的类型，让后续点歌带着这些偏好。

界面支持深浅主题，待播队列可以展开或收起。程序和业务记录保存在本机；生成节目、语音和获取音乐仍会访问相应的在线服务。

## 在熊猫小抽屉里使用

完成配置后，从“我的项目”打开 Radio Bob。平台在后台启动它的 Node 服务，并显示一个原生应用窗口。再次打开会聚焦已有窗口，关闭 Radio 窗口会停止它的服务。

AI 服务需要你自己的 API 密钥，可能消耗服务商额度。普通使用无需安装 Node，也无需安装或登录 Claude Code。

## 当前状态

Radio Bob 目前供内部试用，**公开源码地址和下载包尚未提供**。[安装说明](/apps/radio/install/)介绍已有可信源码时的操作方法。

当前受管版使用游客模式，音乐账号登录关闭。歌曲是否可播、能否完整播放，取决于曲目和上游权限；部分歌曲只有试听。真实 AI 点歌和原生窗口试听已有验证，Fish 语音、长期运行和其他系统仍需分别验收。

它目前没有麦克风输入、定时节目或多设备同步。
