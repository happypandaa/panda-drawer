# Radio Bob

<img src="/images/bob.png" alt="Radio Bob 的像素头像" width="88" height="88">

一台本机运行的个人 AI 电台。说说此刻的心情，或者给 Bob 一个具体的歌手、风格和场景，让它陪你找些音乐。

> “给我三首适合专注工作的歌，轻一点，不要太热闹。”

[查看源码](https://github.com/happypandaa/radio-bob) · [添加与配置](/apps/radio/install/)

## 和 Bob 一起听歌

- **自然语言点歌。** 写下需求，Bob 推荐歌曲，再由应用到曲库匹配可用音源。
- **中文主持串词。** 推荐之外，也有几句简短、松弛的中文介绍。配置 Fish Audio 后可以生成主持口播；不配置语音仍能看文字、听音乐。
- **自己搜索和排队。** 直接找一首歌，立即播放或加入待播队列，用播放器暂停、继续和切歌。
- **保存自己的品味。** 记下喜欢的歌手、风格和不喜欢的类型，让后续点歌带着这些偏好。

界面支持深浅主题，也能显示歌曲封面和歌词。程序在本机运行，生成节目、语音和获取音乐会访问相应在线服务，需要网络与服务额度。

## 使用前先看

Radio Bob 的[源码和使用说明](https://github.com/happypandaa/radio-bob/blob/main/README.md)已经公开。截至 2026-11-03，公开主分支仍使用旧版平台声明，尚未提供当前熊猫小抽屉需要的 `panda.json`。在当前版中使用，需要先让 AI 按项目要求完成适配，不能直接把旧版添加说明照搬过来。

完成适配、添加和配置后，Radio 在自己的窗口中运行。重复打开会聚焦已有窗口，关闭它的窗口会停止后台服务。

选歌使用自己的 DeepSeek API Key，Fish Audio 语音可选。源码版本还提供网易云扫码连接入口；歌曲是否可播、能否完整播放，取决于曲目、账号权限和上游服务，部分歌曲只有试听。

它目前没有麦克风输入、定时节目或多设备同步。本站核对了公开源码与说明，未完成当前项目格式下的重新适配、真实语音或跨系统使用验收。
