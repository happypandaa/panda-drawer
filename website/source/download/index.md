# 下载与系统要求

**熊猫小抽屉目前是内部开发版，正式安装包仍在准备中。** 如果有人邀请你试用，请向对方获取适合你电脑的开发包和安装说明。

## 系统要求

| 系统 | 开发版要求 |
| --- | --- |
| macOS | macOS 15 及以上、Apple Silicon，工作区位于本机或直连磁盘的 APFS 卷 |
| Windows | Windows 10 22H2 或 Windows 11、x64、WebView2 Evergreen，工作区位于本机内置 NTFS 磁盘 |

macOS 提供 AI 工具检测、一键交给 AI、应用窗口标题栏操作和工作区迁移。Windows 可以在应用详情复制提示词、打开项目文件夹，再到自己的 AI 工具继续。

## 最近更新

2026 年 11 月 13 日

- 小抽屉可以切换中英文。应用可以有自己的语言设置。
- 推荐应用增加了拾闻，可以用自己的 AI 按主题收集资讯。
- 修改应用后，可以重新加载查看结果。
