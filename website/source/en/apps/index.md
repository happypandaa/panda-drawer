# Apps

In Panda Drawer, click **Add application** and choose from **Recommended apps**. Click **Add** to download an app. Clack is a good first choice because it works without an account or API key. You can also paste a GitHub or Gitee link into the **App link** field.

## [Clack](/en/apps/clack/)

Choose a Chinese or English passage, type it line by line, then review your speed, accuracy, and mistakes.

{% screenshot a01-clack-practice.webp 1440 746 Clack Quick start screen in Chinese showing passage languages lengths and the Start button %}

The screenshot shows Clack in Chinese. The app also offers an English interface.

**What you need:** No account, API key, or AI tool for regular practice.

App links [GitHub](https://github.com/happypandaa/Clack) · [Gitee](https://gitee.com/mycolorfuldays/clack)

## [Gleaner](/en/apps/gleaner/)

Tell your AI what you want to read about. It gathers and organizes the news, and you can read, save, and leave feedback in Gleaner.

**What you need:** An AI tool that can search the web and read and write local files. Gleaner itself needs no API key.

App links [GitHub](https://github.com/happypandaa/gleaner) · [Gitee](https://gitee.com/mycolorfuldays/gleaner)

## [Readio](/en/apps/readio/)

Listen to English articles sentence by sentence, look up translations, and save sentences and words for later review.

**What you need:** A DeepSeek API key and a Fish Audio API key.

App links [GitHub](https://github.com/happypandaa/Readio) · [Gitee](https://gitee.com/mycolorfuldays/readio)

## [Radio Bob](/en/apps/radio/)

Ask Bob for music. It picks songs and introduces them in Chinese.

**What you need:** A DeepSeek API key. Fish Audio is optional for spoken introductions. [See the setup steps](/en/apps/radio/#Setup).

App links [GitHub](https://github.com/happypandaa/radio-bob) · [Gitee](https://gitee.com/mycolorfuldays/radio-bob)
