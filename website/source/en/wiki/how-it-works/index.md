# How Panda Drawer works with other tools

Panda Drawer adds, opens, and manages apps. You can start by using an app as it comes, like Clack for typing practice. When you want to make its practice text bigger, hand that app to your own AI tool.

## Panda Drawer

Choose an app, fill in its settings if needed, and open it in a separate window. After a change, return to Panda Drawer to open the new version. On macOS, you can click **Reload** in the app window's title bar.

## Your AI tool

Tools such as WorkBuddy and Codex can work with the same project folder as Panda Drawer. Panda Drawer prepares a prompt with the app folder's location. Review and send it in your AI tool, then explain what you want changed. Your AI tool manages its own account and usage limits.

## GitHub and Gitee

The recommended apps' files are hosted on GitHub or Gitee. Panda Drawer downloads them when you click **Add**. Each app has its own project folder, and your AI works on that local copy.

## Online services used by apps

Some apps call online services. Readio, for example, uses DeepSeek to translate text and Fish Audio to read it aloud. Enter the required API keys under **App configuration**. Each provider sets its own usage limits and prices.
