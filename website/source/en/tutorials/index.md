# Tutorials

## Try an existing app

[Practice typing with Clack](/en/apps/clack/#add-and-start-practicing)

Add Clack from **Recommended apps**, finish a short passage, and find your result in **History**. You do not need an AI tool, an account, or an API key.

## Change an app you already use

[Make Clack's practice text bigger](/en/tutorials/remix-an-app/)

Use an AI tool that can edit files on your computer. When it finishes, open Clack again, check the text size, and find your previous result.

## Make your own app

[Build a simple notes app](/en/tutorials/create-your-app/)

Create a starter app and tell your AI what you want. Start with one feature. Write a note, save it, and check that it is still there after reopening the app.
