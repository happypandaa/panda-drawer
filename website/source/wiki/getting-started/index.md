# 入门指南

先选一个现成的小应用用起来。哪里不顺手，就告诉你自己的 AI，把它改成喜欢的样子。

## 1. 准备

先准备好熊猫小抽屉。[当前版本](/wiki/#当前版本)说明获取情况与系统要求。

想修改应用，再准备一个能修改电脑上文件的 AI 工具，例如 Codex、Claude Code、Cursor、Trae 或 WorkBuddy。只用应用、不改功能的话，不需要 AI 工具。

豆包、ChatGPT 网页版等网页版 AI 不能直接修改电脑上的文件，不能用来改应用。[交给你的 AI](/wiki/ai-workspace/)介绍了各工具的用法。

## 2. 添加一个应用

最简单的办法是点「添加应用」，在面板下方的「推荐应用」中选一个，点「添加」。还没有应用时，首页也会直接显示推荐。第一次可以先试 [Clack 打字练习](/apps/clack/)，不需要账号或 API Key。

也可以从这三个入口开始：

- **有应用链接**：粘贴 GitHub 或 Gitee 上的应用地址，点「添加」。
- **本机文件夹**：选择电脑上已有的应用文件夹。
- **从零做一个**：生成一个空白应用，再和 AI 一轮一轮做出来。

添加时会显示进度，每次添加一个。出现准备提示时，按界面确认并等待完成，再打开应用。

如果 AI 需要了解添加要求，让它读[添加应用的规则](/wiki/adding-apps/)。

## 3. 配置并打开

需要 API Key 的应用，在应用详情的「应用配置」中填写自己的 Key，再点「打开」。每个应用有自己的窗口，可以分别打开和关闭。

所需账号、服务和费用见[各应用介绍](/apps/)。密钥填写在软件里，不需要发给 AI。

## 4. 想改哪里，交给你的 AI

macOS 第一次会让你选择 AI 工具，软件会自动检测电脑上装了哪些。以后可以在设置的「我的 AI 工具」里更换；刚装好工具时，可以点「重新检测」。

在应用详情点「用 XX 改」，例如「用 Codex 改」。macOS 的应用窗口标题栏右侧还有「按你的想法改」，也能把当前应用交给 AI。

也可以点「只复制提示词」，自己打开 AI 工具，选择应用的项目文件夹，再粘贴并发送。Windows 使用这条手动路径。

AI 会先读懂应用，再问你想怎么改。说出需求后，它会说明计划，等你同意再动手。

[跟着做：把 Clack 改成自己的 →](/tutorials/remix-an-app/)

## 5. 改完之后

按 AI 的说明操作。有些应用需要先关闭窗口，在详情点「准备应用」，完成后再重新打开。

试一遍新功能，也看看以前保存的内容是否还在。想继续改，就回到同一对话提出下一项需求。

## 6. 国内用户的下载线路

设置里的「下载线路」默认是「自动（推荐）」。也可以手动选「国内线路（Gitee）」或「国外线路（GitHub）」，用于推荐应用的下载。
