# 入门指南

一个小应用可以很简单：练习打字、整理阅读材料，或保存自己的便笺。先让最需要的一件事好用，再一点点完善。

## 准备什么

- 已取得的熊猫小抽屉内部开发版。当前没有公开正式安装包，开发状态见[项目仓库](https://github.com/happypandaa/panda-drawer/tree/develop)。
- 符合所用版本要求的电脑。macOS 面向 15+、Apple Silicon；Windows x64 仍在适配与验收。
- 想制作或修改应用时，准备能读写本机文件的 AI 工具，例如 Codex 或 WorkBuddy。单纯使用应用，无需先安装 AI 编程工具。

熊猫小抽屉不自带 AI。AI 工具的账号和费用由对应提供方管理；应用自身需要的在线服务、账号和费用，另看应用说明。

## 选择一个起点

### 已经找到一个应用

在「我的应用」点击「添加应用」，粘贴作者提供的 GitHub 或 Gitee 公开仓库地址。先看作者的使用前提和当前兼容性，再按界面完成检查与准备。部分版本直接显示「从 Git 添加」。

如果入口提示需要构建，先核对来源与说明，再明确确认。等待最终结果；需要 API Key 的应用先配置，再打开使用。

[看看 Clack、Readio 和 Radio Bob →](/apps/)

### 电脑上已经有应用文件夹

选择「本机文件夹」，让平台检查并添加这个目录。当前格式的根目录应有 `panda.json`。平台直接使用原文件夹，本地添加本身不会复制源码、安装依赖或自动构建。

遇到需要适配、缺少入口或依赖时，保留检查结果，把说明交给 AI 处理。

### 有一个自己的想法

在「添加应用」中选择「从零做一个」，填写名称并创建；部分版本显示「新建」。新应用带有可以打开的初始页面，随后可交给 AI 制作。

也可以从「本机文件夹」选择自己准备的空文件夹，按界面生成起始项目。这个目录由你保留，平台直接使用它。

[开始教程：创建自己的第一个应用 →](/tutorials/create-your-app/)

## 想改哪里，告诉你的 AI

从应用详情选择 AI 工具，使用「用 XX 改」；也可以「只复制提示词」，手动打开工具并选择项目文件夹。核对目录和说明后自行发送，再告诉 AI 想改什么。

当前 macOS 提供工具选择与打开入口；Windows 通过复制说明和手动选择文件夹接手。自动打开也需要你核对，详细步骤见 [AI 目录与交接说明](/wiki/ai-workspace/)。

## 完成第一轮使用

打开应用，完成一项实际操作，再关闭并重新打开，检查内容是否保留。

修改后的应用是否需要准备或重启，按项目说明操作。需要构建的网页应用，先关闭业务窗口，再在详情点击「准备应用」，成功后重新打开。仅在 AI 中看到“完成”，不代表运行中的页面已经换成新版。
