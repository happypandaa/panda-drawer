# 常见问题

## 添加与配置

### 可以添加任何链接吗？

使用作者提供的 GitHub 或 Gitee 应用地址，普通网页或分享链接不一定能添加。最方便的是从「推荐应用」开始。

添加失败时，可以点「交给 AI 处理」，让自己的 AI 检查原因并说明下一步。

### 还要额外安装工具或数据库吗？

熊猫小抽屉会准备应用运行所需的工具。各应用需要的账号、API Key 或 AI 工具，请看[应用列表](/apps/)。

### API Key 填在哪？要花钱吗？

添加需要配置的应用后会显示「应用配置」。也可以在应用详情的「应用配置」点「修改」。把 Key 填在软件里，再点「保存配置」。已经打开的应用重新加载后会使用新的配置。

Clack 无需账号或 Key。Readio 需要 DeepSeek 和 Fish Audio 两个 Key。Radio Bob 需要 DeepSeek，Fish Audio 语音可以选用。使用条件和费用见[各应用介绍](/apps/)。

### 能离线用吗？

取决于应用。Clack 的日常打字练习可以离线使用。翻译、生成语音或在线选歌需要联网。具体前提见[各应用介绍](/apps/)。

## 修改应用

### AI 说改好了，应用为什么没变？

先保存窗口里尚未完成的内容。macOS 可以点应用窗口标题栏上的「重新加载」。[Windows 操作步骤](/wiki/getting-started/#Windows-版的区别)

{% screenshot s06-reload.webp 474 66 macOS 应用窗口标题栏右侧的重新加载按钮 %}

如果 AI 提醒你先准备应用，请关窗，在详情点「准备应用」，完成后再打开。窗口已经打开时，再点「打开」只会切到原来的窗口。遇到错误，把界面提示交给正在修改这个应用的 AI。

### AI 读不到文件怎么办？

从应用详情重新点「只复制提示词」，在 AI 工具中选择其中写明的整个项目文件夹，再粘贴并发送。确认当前 AI 对话能够读取和修改这个文件夹。[查看如何选对文件夹](/wiki/ai-workspace/#选对项目文件夹)

### 改坏了，能撤销吗？

平台会提醒 AI 在修改前保存当前版本。想撤回时，可以直接告诉它「撤销刚才的修改，恢复到修改前的样子」。

这份版本用于还原应用功能，练习记录等数据要另外保存。动数据前，AI 会先说明影响并征求你的同意。保存规则见[平台规则](/wiki/platform-rules/)。

## 数据与删除

### 我的数据存在哪？会丢吗？

数据保存在这台电脑上，分两类。

- **应用窗口里的浏览器数据**由应用窗口单独保存。删除应用时会清除，即使保留了项目文件夹，重新添加也读不回来。
- **项目文件夹里的文件数据**跟随该文件夹保存。删除时是否保留，取决于应用是怎样添加的。

重要内容要另外保存。例如 Readio 可以在应用内「⋯」菜单中「导出备份」，以后再导入。各应用的保存方式与删除范围见[数据说明](/wiki/data-and-config/)。

### 关闭窗口会怎样？

关闭应用窗口会停止这个应用，再次打开会使用已保存的内容。同一应用重复打开只会切到已有窗口。

macOS 关闭熊猫小抽屉管理窗口只会隐藏它，点 Dock 图标可以回来。要退出软件并关闭全部应用，可以从菜单退出或按 `Cmd+Q`。Windows 关闭管理窗口会退出软件。

### 删除应用会删掉文件吗？

删除前先看确认窗口里的范围。

| 添加时选择的位置 | 项目文件夹和其中的数据 | 应用配置、Key 和浏览器数据 |
| --- | --- | --- |
| 自选位置，例如用「本机文件夹」添加、在自选空文件夹新建或把拾闻放到自选空文件夹 | 保留 | 清除 |
| 默认位置，例如从推荐应用或应用链接添加 | 清除 | 清除 |

删除无法撤销。已经另存到其他位置的下载文件和备份会保留。若你在自己的 AI 工具里为拾闻等应用安排了定时任务，先在那里停止这些任务。详细范围见[数据与删除说明](/wiki/data-and-config/)。

### 卸载会删除应用吗？

普通卸载会保留应用和数据。准备全部清空时，可以先使用设置中的「清理所有本机项目内容」，按提示查看范围并确认，再退出和卸载。

使用第三方清理工具时，也要查看它准备删除哪些文件，确认需要的数据已保存。

## 下载与系统

### 支持什么系统？在哪下载？

在[下载页](/download/)可以查看发布状态和系统要求。

### 国内下载慢怎么办？

在设置的「下载线路」中选择「国内线路（Gitee）」，或保留「自动（推荐）」让软件检测。需要时可切换到「国外线路（GitHub）」。这项设置影响推荐应用的下载。
