# 常见问题

## AI 说改好了，应用为什么没变？

网页项目修改源码后，需要点击详情上方的「构建更新」，等待成功，再处理窗口中的未保存内容。在「概览 → 详细运行信息」点击「重新加载项目窗口」并明确确认。旧窗口不会自动刷新。构建失败会保留旧网页，但已提交的数据库修改不会因此自动撤销。

## AI 读不到项目文件怎么办？

重新打开项目详情，点击「复制提示词」取得最新的 AI 接手说明，核对「本次项目目录」。在 Codex 或 WorkBuddy 中关联这一整个本机目录，并确认当前任务有权读取。详细步骤见 [目录关联说明](/wiki/ai-workspace/)。

## 需要安装 Node 或数据库吗？

打开初始网页与已构建的网页项目，不要求另装数据库服务器或系统 Node。当前 Mac 内部版也为平台构建和受管 Node 应用提供配套工具。应用仍须符合受支持格式，所需运行依赖必须准备齐全；额外软件要求以应用说明为准。

## 所有应用都可以离线使用吗？

取决于应用。本地信息管理可以使用平台数据能力；Radio 的 AI、音乐和语音服务需要联网，也可能需要账号、Key 或付费额度。先看每个应用的使用前提。

## API Key 填在哪里？

需要配置的应用，会在平台的「应用配置」中显示作者声明的字段与说明。请填写自己的密钥，不把它写进源码、Git、聊天示例或分享包。当前本机私有配置使用文件权限保护，不能当作系统加密密钥库。

## 让 AI 保存 Git 版本，是否保存了所有数据？

没有。普通详情不再提供源码版本面板，Git 管理由 AI 通过项目工具处理。当前平台 Git 保存不含数据库、附件和运行产物。需要完整归档时，在「更多操作」点击「导出 ZIP」，核对包含当前业务数据的说明后选择位置。迁移仍使用平台支持的工作区迁移入口；不要靠手工搬目录或覆盖数据库来恢复。

## 详情提示有一项操作需要处理怎么办？

点击「查看并处理」，重新核对旧维护、恢复或未完成源码取回的状态。界面只提供已核验允许的动作，结束维护、继续或撤回都需明确确认；处理源码前要停止外部编辑与 Git 操作。失败或状态无法核实时保留现场和日志，让 AI 根据记录检查，不要反复提交或删除恢复材料来绕过保护。

## 可以直接安装任何 GitHub 仓库吗？

不能。「获取项目源码」先下载和检查。只有符合当前 Node 源码安装要求的候选，才能进一步准备、确认安装；其他项目需要先适配。拿到平台完整项目 ZIP 时，使用「导入项目」。

## 关闭窗口会发生什么？

关闭 Node 应用自己的业务窗口，会停止它的后台服务。重复打开会聚焦已有窗口。在 macOS 上关闭熊猫小抽屉的管理窗口只会隐藏；菜单退出或 Cmd+Q 才会退出平台并安全收尾全部应用。

## 删除项目后，可以从回收站找回来吗？

不能。当前规则是确认后直接永久删除，**不进入熊猫小抽屉的回收站，也不进入系统废纸篓**。删除前会显示应用名称、删除目录及保留范围；不确定时先取消。

平台新建／导入的项目、已安装应用会删除所选实例的程序或源码及本机数据和配置。通过外部文件夹引用接入的应用，只删除平台登记和该实例的本机配置／数据，原外部文件夹保留；删除前请核对提示。Node 应用先关闭自己的业务窗口，再删除。

旧版本已经留下的备份、旧回收项和恢复记录不会随本次删除一起清空。旧回收项仍可按原入口处理，这不代表新删除可以撤销。

## 卸载熊猫小抽屉，会删除项目吗？

普通卸载默认保留项目。macOS 把 `.app` 移到废纸篓只移除平台程序；使用第三方清理工具时，若同时删除应用数据目录，其中的项目和数据也会丢失。Windows 的安装、卸载和重装行为仍待实际验收。

如果准备连同受管项目一起清空，设置中的“清理所有本机项目内容”通常在卸载前使用。它需要两次明确确认，永久删除小抽屉管理的本机源码、数据库、附件、已安装应用、配置／Key 和旧备份、旧回收与恢复资料，无法从回收站撤销。外部原始源码目录、范围之外的独立 ZIP／导出包及平台程序保留；极少量实例锁和清理回执用于核对结果。

当前开发标识为 `dev.happypandaa.pandadrawer`。2026-10-25 用户单独明确选择清空旧开发实例的项目、业务数据和旧系统状态，使用新身份重新开始；实际清理与新环境验收另记。这是针对旧开发环境的一次独立授权，普通升级和卸载仍按上文规则保留资料。

新身份 Mac 开发版的主要位置如下，实际数据根和工作区以软件显示为准；删除 `.app` 不会自动移除以后保存在这些位置的资料：

| 位置 | 保存内容及清理边界 |
| --- | --- |
| `~/Library/Application Support/dev.happypandaa.pandadrawer/` | 固定数据根，含工作区和以后安装的 Node 应用；受管业务内容属于设置清理范围，最小锁和回执保留 |
| `~/Library/WebKit/dev.happypandaa.pandadrawer/` | 新身份运行后可能生成的网页引擎存储，设置清理入口不删除 |
| `~/Library/Caches/dev.happypandaa.pandadrawer/` | 新身份运行后可能生成的系统或网页引擎缓存，设置清理入口不删除 |
| `~/Library/Preferences/dev.happypandaa.pandadrawer.plist` | 新身份运行后可能生成的系统应用偏好，设置清理入口不删除 |

网页存储可能包含网页会话、localStorage 等数据，主题偏好也使用 localStorage，不能将它们一概当作没有敏感内容的临时缓存。本次单独授权的旧开发环境重置会删除旧标识的三处系统状态，不将旧网页会话或主题带入新空环境；外部原作者源码和平台工程保留。正常设置清理仍只覆盖列出的受管项目和配置，**不保证整台机器零残留**；范围外系统记录、独立 ZIP、导出包或下载的 DMG 不会自动删除。以上是开发身份的位置；未来正式版使用独立身份 `com.happypandaa.pandadrawer`，正式运行和安装验收尚未完成。

请先停止外部编辑器、AI 和数据库工具访问待清理目录，逐项核对提示。完整清理成功后退出软件，再自行卸载；若提示失败或结果未知，先查看剩余范围，不要当作全部完成。清理不会自动搜索全盘或删除用户其他开发目录。

## 现在支持什么系统？在哪里下载？

目前是面向 macOS 15+、Apple Silicon 的内部开发版，最低支持系统与公开正式发行仍待验收。Windows 是支持目标，实际安装运行尚未验收。以 [项目仓库](https://github.com/happypandaa/panda-drawer) 的发布说明为准。
