# 常见问题

## AI 说改好了，应用为什么没变？

按 AI 的说明完成后续操作。有些应用需要先保存未完成的内容、关闭窗口，在详情点「准备应用」，成功后再重新打开。

再次点「打开」可能只会切到已有窗口。遇到准备失败或仍然没有变化，把界面提示交给正在修改这个应用的 AI。具体规则见[运行方式说明](/wiki/app-types/)。

## AI 读不到文件怎么办？

从应用详情重新点「只复制提示词」，在 AI 工具中选择其中写明的整个项目文件夹，再粘贴并发送。确认当前 AI 对话能够读取和修改这个文件夹。

[交给你的 AI](/wiki/ai-workspace/)中有工具说明和 Trae 的操作步骤。

## 改坏了，能撤销吗？

平台规则要求 AI 修改前先保存当前版本。想撤回时，可以直接告诉它：「撤销刚才的修改，恢复到修改前的样子。」

这份版本用于还原应用功能，练习记录等数据要另外保存。动数据前，AI 会先说明影响并征求你的同意。保存规则见[平台规则](/wiki/platform-rules/)。

## 可以添加任何链接吗？

使用作者提供的 GitHub 或 Gitee 应用地址，普通网页或分享链接不一定能添加。最方便的是从「推荐应用」开始。

添加失败时，可以把提示交给 AI，先让它说明原因和下一步。给 AI 的详细要求见[添加应用的规则](/wiki/adding-apps/)。

## 还要额外安装工具或数据库吗？

不需要为使用受支持的应用另外安装运行工具或数据库。先按应用介绍准备必要账号和 API Key；修改应用时，再使用自己的 AI 工具。

## 能离线用吗？

取决于应用。Clack 的日常打字练习可以离线使用；翻译、生成语音或在线选歌需要联网。具体前提见[各应用介绍](/apps/)。

## API Key 填在哪？要花钱吗？

在应用详情的「应用配置」填写自己的 Key，不需要把密钥发给 AI。

[Clack](/apps/clack/)不需要账号或 Key；[Readio](/apps/readio/)需要 DeepSeek 和豆包语音两个 Key，两个服务都按量付费；[Radio Bob](/apps/radio/)需要 DeepSeek，Fish Audio 语音可以选用。服务费用由对应提供方收取，自己的 AI 工具账号另外计算。

## 我的数据存在哪？会丢吗？

数据保存在这台电脑上，分两类：

- **应用窗口里的浏览器数据**：由应用窗口单独保存，不在项目文件夹里。删除应用时会清除，即使保留了项目文件夹，重新添加也读不回来。
- **项目文件夹里的文件数据**：跟随该文件夹保存，删除时是否保留，取决于应用是怎样添加的。

重要内容要另外保存。例如 Readio 可以在应用内「⋯」菜单中「导出备份」，以后再导入。各应用的保存方式与删除范围见[数据说明](/wiki/data-and-config/)。

## 关闭窗口会怎样？

关闭应用窗口会停止这个应用，再次打开会使用已保存的内容。同一应用重复打开只会切到已有窗口。

macOS 关闭熊猫小抽屉管理窗口只会隐藏它，点 Dock 图标可以回来；菜单退出或 `Cmd+Q` 才会退出软件并关闭全部应用。Windows 关闭管理窗口会退出软件。

## 删除应用会删掉文件吗？

删除前先看确认窗口里的范围：

- 通过「本机文件夹」添加的，保留你选择的项目文件夹和其中的数据；在自己选择的空文件夹里生成的应用也一样。
- 从推荐或应用链接添加，以及通过「从零做一个」生成的，删除时会连同项目文件夹和其中的数据一起清除。

两种情况都会清除应用配置、Key 和浏览器数据，删除无法撤销。已经另存到外部位置的下载文件和备份保留。详细范围见[数据与删除说明](/wiki/data-and-config/)。

## 卸载会删除应用吗？

普通卸载会保留应用和数据。准备全部清空时，可以先使用设置中的「清理所有本机项目内容」，按提示查看范围并确认，再退出和卸载。

使用第三方清理工具时，也要查看它准备删除哪些文件。不要把仍需要的数据一起清理。

## 支持什么系统？在哪下载？

系统支持与获取情况集中写在 Wiki 的[当前版本](/wiki/#当前版本)。

## 国内下载慢怎么办？

在设置的「下载线路」中选择「国内线路（Gitee）」；也可以保留「自动（推荐）」，让软件检测。需要时还可切换到「国外线路（GitHub）」。这项设置影响推荐应用的下载。
