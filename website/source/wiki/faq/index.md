# 常见问题

## AI 说改好了，应用为什么没变？

先看项目说明。需要构建的网页应用，先关闭业务窗口，再到详情点击「准备应用」，等待最终成功后重新打开。Node 后端修改后需要重新启动；只是再次进入一个已打开的应用，通常只会聚焦原窗口。

当前构建直接使用项目原目录，失败可能留下已修改的文件。保留日志交给 AI 修复，不能按旧教程假定平台保留了上一版程序。

## AI 读不到项目文件怎么办？

从当前应用详情重新复制提示词，核对完整项目目录。在 AI 工具里选择这个目录，并确认当前对话可以读取和修改文件。自动打开失败时，也可以手动关联后粘贴说明。见 [AI 交接指南](/wiki/ai-workspace/)。

## 可以添加任何 GitHub 仓库吗？

不能。当前支持公开 GitHub／Gitee HTTPS 仓库，应用需要符合根目录 `panda.json` 格式及对应运行要求。普通源码 ZIP、旧清单或任意网站工程不保证能直接运行。检查提示需要适配时，把结果交给 AI，先按当前要求处理。

## 需要安装 Node 或数据库吗？

使用已准备好的受支持应用，不要求另装数据库服务器或系统 Node，平台提供配套运行工具。额外软件、生产依赖和应用服务仍需符合各自要求；本地文件夹添加不会代替作者安装依赖。

## 所有应用都能离线使用吗？

取决于应用。本地功能可以离线工作；需要 AI、音乐、翻译或语音服务的功能仍要联网，并可能需要账号、Key 或付费额度。先阅读[每个应用的说明](/apps/)。

## API Key 填在哪里？

需要配置的应用会显示作者声明的配置字段与获取说明。填写自己的账号密钥，不写进源码、Git 或分享材料。秘密值由平台保存在本机私有配置中，只交给对应后端；保存成功不代表服务商已验证密钥和额度。

## 保存 Git 版本，是否保存了所有数据？

不一定，取决于项目实际纳入 Git 的文件。项目中的 `data/`、浏览器存储和平台私有配置是不同内容，不能把一次源码提交当成整份数据备份。

平台已移除项目 ZIP 导入导出、复制和版本取回。需要备份或分享时，让 AI 先核对项目实际数据与保存方式，不要直接覆盖使用中的数据库。

## 关闭窗口会发生什么？

关闭应用自己的业务窗口，会收尾它的服务。重复打开会聚焦已有窗口。在 macOS 上关闭熊猫小抽屉管理窗口只会隐藏，菜单退出或 `Cmd+Q` 才退出平台并收尾全部应用；Windows 关闭管理窗口会退出平台。

## 删除应用会不会删掉源文件？

先看来源和确认窗口：

- **本机文件夹**：保留你选择的整个目录，包括源码、Git 和 `data/`；在你选择的空目录生成的起始项目也遵循这条规则。
- **平台新建或 Git 下载的应用**：删除平台管理的整个项目目录，包括源码、Git、文件数据和依赖。

两类都会清除平台登记、配置、密钥、日志、缓存、任务和应用窗口的浏览器数据。删除不进入平台回收站或系统废纸篓，无法撤销。

已经完成并保存到你所选外部位置的下载、导出文件和附件副本会保留；项目里的原件与内部临时材料随所属项目删除。不要根据旧结果路径猜测删除范围，先核对界面提示。

## 卸载熊猫小抽屉，会删除项目吗？

普通卸载默认保留项目和数据。若同时使用第三方工具删除应用数据目录，其中的受管项目也可能丢失。

准备清空时，可在卸载前使用设置中的「清理所有本机项目内容」。逐项查看范围并完成两次确认后，它会永久清理平台管理的项目和私有内容，保留用户原始目录及范围之外的已完成外部文件。按结果核对剩余内容，再退出和卸载，不把部分失败视为清理成功。

## 现在支持什么系统？在哪里下载？

当前是内部开发版，**公开正式安装包尚未发布**。macOS 面向 15+、Apple Silicon，最低系统与正式发行仍待验收。Windows x64 已有 Windows 11 的部分安装、运行及卸载重装验证，整体适配验收尚未完成；不代表 Windows 10 或最新全部流程已经通过。

开发状态与说明以[项目仓库](https://github.com/happypandaa/panda-drawer/tree/develop)为准。本站不会把计划中的支持或历史测试写成当前完整验收。
