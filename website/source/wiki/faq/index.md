# 常见问题

## AI 说改好了，应用为什么没变？

网页项目修改源码后，需要「构建项目」，等待成功，再处理窗口中的未保存内容，明确重新加载项目窗口。旧窗口不会自动刷新。构建失败会保留旧网页，但已提交的数据库修改不会因此自动撤销。

## AI 读不到项目文件怎么办？

重新打开项目详情，复制最新的 AI 接手说明，核对「本次项目目录」。在 Codex 或 WorkBuddy 中关联这一整个本机目录，并确认当前任务有权读取。详细步骤见 [目录关联说明](/wiki/ai-workspace/)。

## 需要安装 Node 或数据库吗？

打开初始网页与已构建的网页项目，不要求另装数据库服务器或系统 Node。当前 Mac 内部版也为平台构建和受管 Node 应用提供配套工具。应用仍须符合受支持格式，所需运行依赖必须准备齐全；额外软件要求以应用说明为准。

## 所有应用都可以离线使用吗？

取决于应用。本地信息管理可以使用平台数据能力；Radio 的 AI、音乐和语音服务需要联网，也可能需要账号、Key 或付费额度。先看每个应用的使用前提。

## API Key 填在哪里？

需要配置的应用，会在平台的「应用配置」中显示作者声明的字段与说明。请填写自己的密钥，不把它写进源码、Git、聊天示例或分享包。当前本机私有配置使用文件权限保护，不能当作系统加密密钥库。

## 保存源码版本，是否保存了所有数据？

没有。当前源码版本不含数据库、附件和运行产物。数据保护与迁移使用平台已支持的对应入口；不要靠手工搬目录或覆盖数据库来恢复。

## 可以直接安装任何 GitHub 仓库吗？

不能。「获取项目源码」先下载和检查。只有符合当前 Node 源码安装要求的候选，才能进一步准备、确认安装；其他项目需要先适配。拿到平台完整项目 ZIP 时，使用「导入项目」。

## 关闭窗口会发生什么？

关闭 Node 应用自己的业务窗口，会停止它的后台服务。重复打开会聚焦已有窗口。在 macOS 上关闭熊猫抽屉的管理窗口只会隐藏；菜单退出或 Cmd+Q 才会退出平台并安全收尾全部应用。

## 删除项目后，可以从回收站找回来吗？

不能。当前规则是确认后直接永久删除，**不进入熊猫抽屉的回收站，也不进入系统废纸篓**。删除前会显示应用名称、删除目录及保留范围；不确定时先取消。

平台新建／导入的项目、已安装应用会删除所选实例的程序或源码及本机数据和配置。通过外部文件夹引用接入的应用，只删除平台登记和该实例的本机配置／数据，原外部文件夹保留；删除前请核对提示。Node 应用先关闭自己的业务窗口，再删除。

旧版本已经留下的备份、旧回收项和恢复记录不会随本次删除一起清空。旧回收项仍可按原入口处理，这不代表新删除可以撤销。

## 现在支持什么系统？在哪里下载？

目前是面向 macOS 15+、Apple Silicon 的内部开发版，最低支持系统与公开正式发行仍待验收。Windows 是支持目标，实际安装运行尚未验收。以 [项目仓库](https://github.com/happypandaa/postgresUI) 的发布说明为准。
