# 熊猫小抽屉和其他软件

熊猫小抽屉负责添加、打开和管理应用。你可以先用现成的应用，例如用 Clack 练打字。想把练习的字调大时，再把这个应用交给你自己的 AI 工具。

## 熊猫小抽屉

你可以在小抽屉里挑应用、填配置、打开应用窗口。修改完应用后，回到这里打开新版。在 macOS 上，可以点应用窗口右上角的「重新加载」。

## 你的 AI 工具

WorkBuddy、Codex 等能操作本机文件的工具可以打开同一个项目文件夹。小抽屉会准备好一段说明，告诉 AI 应用放在哪里。确认后发送，再说出你想改的地方。用到的 AI 账号和额度由你自己的工具管理。

## GitHub 和 Gitee

推荐应用的文件放在 GitHub 或 Gitee。你点「添加」后，小抽屉会替你下载。应用有自己的项目文件夹，AI 修改的是你电脑上的那一份。

## 应用所用的在线服务

部分应用会调用在线服务。例如 Readio 用 DeepSeek 翻译，用 Fish Audio 朗读。用到服务密钥时，在小抽屉的「应用配置」填写。服务的额度和费用由提供方决定。
