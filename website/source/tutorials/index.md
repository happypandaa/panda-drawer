# 教程

从一个小需求开始，做一个自己每天都会用的应用。熊猫小抽屉负责运行和管理，制作和修改交给你自己的 AI。

## 从零开始

**01 / [用 AI 创建自己的第一个应用](/tutorials/create-your-app/)**

以便笺为例，创建初始应用，让 AI 读懂说明并实现功能，再按项目要求准备、打开，保存内容并关闭重开验证。

## 从喜欢的应用开始

**02 / [获取一个应用，再改成自己的](/tutorials/remix-an-app/)**

通过 Git 链接或本机文件夹添加应用，核对兼容性、目录与数据，再交给 AI 修改。旧版项目 ZIP 和平台复制流程已经移除。

## 先看这几个问题

- 不确定关联哪个文件夹？读 [给 AI 关联正确的项目目录](/wiki/ai-workspace/)。
- 不清楚应用的文件和数据放在哪里？读 [应用类型与文件](/wiki/app-types/)。
- 想先体验一个现成应用？去看[应用列表](/apps/)。

教程更新于 2026-11-03，按当前内部开发版编写。macOS 提供 AI 工具打开入口，Windows 当前手动复制说明；实际按钮以所用版本为准。
