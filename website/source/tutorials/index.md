# 教程

从一个小需求开始，做一个自己每天都会用的应用。

这里的教程会带你走完「准备项目 → 关联文件夹 → 告诉 AI 需求 → 构建 → 打开使用」的完整过程。每篇都包含 Codex 和 WorkBuddy 的接手方法，选你正在使用的工具就好。

## 从零开始

**01 / [用 AI 创建自己的第一个应用](/tutorials/create-your-app/)**

以本地便笺为例，在熊猫抽屉中新建项目，让 AI 读懂项目说明并实现功能，最后保存一条真实数据，关闭重开验证。

## 从喜欢的应用开始

**02 / [复制别人的应用，改成自己的](/tutorials/remix-an-app/)**

分清完整项目 ZIP、已有项目和公开源码仓库，创建独立副本，再把新副本的正确文件夹关联给 AI，增加自己需要的功能。

## 先看这几个问题

- 不确定关联哪个文件夹？读 [给 AI 关联正确的项目目录](/wiki/ai-workspace/)。
- 不清楚网页项目和 Node 应用的区别？读 [应用类型与文件](/wiki/app-types/)。
- 想先用现成应用？去看 [Radio Bob](/apps/radio/)。

教程依据当前 macOS 内部开发版编写，界面以所用版本为准。首次使用建议从可丢弃的练习项目开始。
