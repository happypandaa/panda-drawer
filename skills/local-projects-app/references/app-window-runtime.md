# 窗口、网页环境与数据

## 窗口

- 应用在平台提供的单个原生窗口里运行，不需要用户另开浏览器。再次打开同一个应用只会聚焦已有窗口，不刷新页面、不启动第二份服务。
- 真正关闭后再打开，才会读取最新的 panda.json、配置和网页文件。修改代码或构建前，提醒用户先关闭应用窗口。
- 窗口大小：panda.json 可以写 `{"window": {"width": 960, "height": 640, "rememberSize": true}}`。不写时默认 1080×780，并记住用户调整后的大小；写了则宽、高都必填（1–32768 的整数）。实际最小内容区为 640×480。
- `alert`、`confirm`、`prompt` 可以使用，由系统原生对话框显示。外部链接和 `window.open` 会用系统浏览器打开，不会在平台里新建窗口。

## 网页环境

- 每个应用有固定不变的本机地址（`http://127.0.0.1:<端口>`），网页从根路径提供，用 `/assets/...` 这类绝对路径引用资源没有问题。因为地址固定，localStorage、IndexedDB、Cookie 在下次打开时仍然可用。
- 请求一个不存在、且没有扩展名的页面路径时，返回首页，所以 React Router 等前端路由刷新不会白屏；资源文件和 `/_platform/` 下的路径不会这样回退。
- `/_platform/` 是平台保留路径：`sdk.js`（SDK 脚本）、`config.json`（用户配置）、`api/v1/`（SDK 接口）。项目里不要使用这个路径。
- 网页服务不提供项目的 `data/`、`node_modules/`、以 `.` 开头的文件和目录、`panda.json`，以及链接到项目外或有多个硬链接的文件。网页目录里普通的 `assets/data/` 不受影响。
- 安全策略允许：内联脚本和 `onclick` 等事件属性、`eval`，从 https 地址加载脚本、样式、字体、图片和媒体，以及 data:、blob: 图片和媒体。不允许：`<object>` 嵌入、被其他页面嵌入。
- 页面主动发起的请求（`fetch`、XMLHttpRequest、WebSocket）只能访问本应用自己的地址，以及 panda.json 的 `runtimeRequirements.network.connect` 里声明的地址（每项写明 `origin`、`purpose`、`dataSent`），对方服务还要允许跨域。摄像头、麦克风要在 `runtimeRequirements.devices` 中写明用途，并经系统授权。
- Node 应用的网页经平台代理访问后端，同源调用即可；它同样不能直接请求外部地址，请改由后端去请求。

## 数据

- **文件数据**在项目 data/。网页启用 SDK 时，数据库为 `data/main.sqlite`，附件在 `data/attachments/`，首次使用时创建；数据库文件不存在就新建空库，文件损坏会报错，平台不会自动修复或重置。Node 后端写到 `APP_DATA_DIR`（即 data/）。
- 普通应用打开时，通过平台 CLI 的 `db` 命令或 SDK 修改数据库；完全关闭后可直接用 SQLite 工具操作。agent 日常任务可在应用开着时按 `agent-apps.md` 的短事务规则直接读写同一个数据库。不要替换正在使用的数据库文件，或删除其 `-wal`、`-shm` 文件。
- 外部放入 `data/attachments/` 的普通文件可通过 `panda.files.list`、`get`、`url`、`remove` 使用，无需先经 SDK 上传；路径边界、符号链接和硬链接等安全检查仍然适用。
- 外部数据库或附件写入不会产生 SDK 的 `data.changed` 事件，应用须自行重新查询。平台存储统计是扫描快照，外部写入不会自动使缓存失效；需要最新占用时重新扫描，`stale: false` 不证明包含了所有外部变化。
- `panda.context.get().projectRoot` 返回当前应用根目录的绝对路径，使用系统原生格式，可供应用生成交给 AI 的工作目录提示。它不返回工作区或其他应用路径，调用仍需启用网页 SDK。
- **浏览器数据**（localStorage、IndexedDB、Cookie）保存在平台的窗口存储里，按应用实例隔离，不在项目文件夹中。删除应用时一定清除；同一文件夹重新添加会成为新的实例，读不回原来的浏览器数据。
- 平台不备份、不迁移、不校验业务数据。代码用 Git 保存；数据是否备份或提交，由用户自己决定。

## 配置和密钥

- 配置项在 panda.json 中声明，用户在平台表单填写。不要让用户维护 .env，也不要让用户把 Key 发给你。
- Node 的配置和密钥只注入后端；网页只能读普通配置，不能声明密钥。
- 密钥保存在平台私有目录，受当前用户的文件权限保护，是明文文件，不是系统加密库。不要读取平台登记、密钥文件或其他应用的配置。

## 验证

用明确命名、可以丢弃的测试项目验证：首次打开、再次打开只聚焦、关闭后重开数据仍在、修改配置后生效、出错时的提示。接口或页面测试不能代替真实的原生窗口、系统权限和设备验收，只报告实际测到的结果。
