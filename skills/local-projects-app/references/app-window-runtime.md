# 应用环境、窗口与数据边界

2026-11-01，统一清单批次 2。网页和 Node 均使用 panda.json 并直接运行原目录；独立地址和新的全局 SDK 脚本尚未交付。

## Node 交付

- 只读取项目根的 panda.json，manifestVersion 为 1、runtime 为 node。app.name 必填；名称、版本、图标、入口、配置和 window 可修改，关闭再打开生效。不声明实例 ID、development、platform、runtimeRequirements 或数据路径。
- 网页和后端入口都必须存在并可直接运行，不交付仅有 TSX 或需开发服务器的应用。平台启动一个固定 Node 24 后端；stdout 仅用于 NDJSON 控制协议，日志写 stderr。
- initialize 核对协议、instanceId 和本次 token；后端监听 APP_HOST/APP_PORT，报告 ready。HTTP 核对 Bearer token，健康检查、ping/pong 和 shutdown/stopping 遵循平台协议。stdin 关闭同样结束服务，不创建脱离平台的后台服务。
- 本地登记不安装依赖。Git 获取只准备一组有效 npm 包及 v2/v3 锁文件，执行 npm ci --omit=dev --ignore-scripts。无包零依赖项目跳过。平台不为 Node 执行构建或生命周期脚本。第三方原生扩展、多服务、通用 CLI 不属于已支持子集。
- 不依赖宿主 PATH、全局包、作者绝对路径、未声明环境变量或临时开发服务器。受管 Node 和窗口不是系统权限沙箱。

## 网页交付

网页使用 runtime:web、web.root／entry，无需后端、SDK 或构建声明。platform.sdkApiVersion=1 启用当前 SQL／附件接口，文件数据按需写入 data/；普通网页不提前创建数据库。有效声明但缺入口可登记为需要构建或入口缺失。

development.sourceDir 默认点，构建执行受管 npm ci 与 npm run 指定 script，脚本自行输出到所声明入口。构建前关窗，窗口打开时构建被拒绝。平台不复制工程、不追加 outDir、不保存旧代次、不计算来源匹配或回滚文件。当前仍使用 /p/<实例ID>/ 地址、SDK 包及模板 base './'。

## 数据、归属和配置

- Node 的 APP_DATA_DIR 是项目 data/，启动前创建；APP_CACHE_DIR、APP_TEMP_DIR、日志、实际配置和密钥在平台私有目录。修改或清空业务数据前先说明并取得用户同意。
- 用户选择的本地文件夹（包括平台在空文件夹里生成的代码）属于用户，删除应用时保留文件夹、Git 和 data/。Git 下载的项目属于平台，删除时整个文件夹一起删除。
- localStorage、IndexedDB 和 Cookie 是平台窗口的浏览器数据，删除应用时总会清除；即使文件夹保留，重新添加也无法恢复该实例的浏览器数据。长期文件数据应放在 data/。
- 用项目自己的 Git 保存和回退代码。平台不提供源码或数据版本、恢复、ZIP 导入导出及项目复制。代码保存不能代替业务数据备份。
- 配置项来自清单，真实值从平台表单填写，不另建 .env。Key 只注入目标后端，不放入网页、日志、提示词或截图；不读取其他应用或宿主秘密。
- Node 私有秘密文件受当前用户文件权限保护，属于明文文件，不是系统加密库。AI 不直接读取或修改平台登记与凭据。

## 窗口

同一应用再次打开只聚焦已有窗口，不刷新草稿或启动第二个服务。真正关闭后再打开才读取当前清单和配置。修改代码前提醒关闭应用窗口。

清单可选顶层 window：

```json
{ "window": { "width": 960, "height": 640, "rememberSize": true } }
```

省略时默认 1080×780 并记忆尺寸；提供对象时宽高都必填，为 1..32768 的整数，rememberSize 默认 true。实际最小内容区为 640×480，并按显示器可用区收敛。平台按实例存储普通窗口尺寸；AI 不修改尺寸缓存。已有窗口只聚焦，不重设尺寸。

当前批次仍沿用原生窗口的既有对话框、外部链接和 CSP 约束；不把后续独立服务及放宽策略写成已上线。业务表单和确认优先在当前窗口内完成。

macOS 管理窗口关闭只隐藏；Dock 或重复启动恢复同一管理窗口。明确退出才收尾全部业务窗口、受管后端和普通子进程，不能终止用户独立启动的服务。其他平台管理窗口关闭按其适配层行为处理。

停止应用必须完成进程及连接收尾，失败应显示实际未完成原因。浏览器数据删除须等待原生窗口销毁与系统清理确认；只关窗口不能算已清除。

## 工具与验证

平台保留 Node/npm 和 Git 工具诊断、显式选择，以及公开 HTTPS 仓库 HEAD 检查；失效时不悄悄回退。不要读取 SSH 私钥或修改全局配置，运行应用不依赖 Git。

新清单不读取旧格式，不迁移或清理旧材料。开发应用身份固定为 dev.happypandaa.pandadrawer，普通工作不重置数据根。工作区移动只能使用已开放的公开迁移流程。

使用明确命名的可丢弃项目验证首次打开、重复聚焦、关闭后端、重开文件数据保留、配置变化和异常提示。HTTP 或 DOM 测试不能代替真实原生窗口、系统权限和设备验收；只记录实测行为。原始业务数据及已完成的外部文件交付不属于普通维护的删除范围。
